# HTML 连续阅读、持久化与导入性能

用户确认：已入库论文打开及连续滚动要达到毫秒级体验，不逐页翻动；首次导入可等待，但显示实际阶段和进度。重排结果持久保存，不能每次打开重新组合；同时减少导入开销与冗余存储。

用户进一步确认采用本地 HTML，以便未来扩展交互；手写内嵌另行设计。此前拟议的最终 PDF 合并方案撤下，不作为本次实现。

## 内容与存储

- 新重排保存一套本地 HTML 阅读结果和实际引用的资源，加一份不可覆盖的原始 PDF。图片按内容哈希去重；SVG 原样显示，图内文字不翻译。正文、译文、来源、稳定块 ID 与批注元数据保留，不长期保存中间 PDF、下载 HTML 或图片副本。
- HTML 正文连续排列，无纸张分页或页尾填充。按稳定内容块追加英中段落，已有内容不改写；界面宽度可自适应，手写暂不进入 HTML，不承诺跨宽度的几何坐标一致。
- 每批先生成完整新 HTML，再提交数据库引用，再清理旧 HTML；资源复用，未提交资源启动时回收。取消/失败保留已提交版本。事务期间短暂保留新旧文件，不属于长期缓存。
- 已有 PDF 重排及其批注继续按旧格式读取；不强制迁移或删除带用户记录的版式。快照显式升级，新增可选 HTML 制品字段，原有 ID 保持不变。
- 上传 PDF 的普通文本生成 HTML；复杂页保留整页图片并提供原版定位，避免丢图表。全篇无法可靠提取的文件仍明确使用原版，OCR 尚未加入。

## 阅读器

- 原生 WKWebView 直接读取已保存 HTML，采用非持久化网站存储，仅应用脚本桥接，不允许论文脚本、远程资源或任意文件导航。
- 稳定内容块支持阅读位置、书签、选文解释、证据跳转。HTML 高亮以文本范围绑定块，不沿用 PDF 坐标；原有 PDF 笔迹不迁移。跨块选文必须明确处理，不能把多块文字错误归给一个来源。
- 渐进翻译只追加新块，不重新加载整个阅读器或打断滚动；再次打开直接读取当前已提交版本。
- 图片保留宽高比例、延迟解码；页面不持久缓存预渲染位图。网络资源下载失败时沿用已实现的像素裁剪/整页保留流程。

## 导入与验证

- 结构化内容通过覆盖检查后，跳过重复的 PDF 分栏重排；已确定保留原版的复杂页不再计算分栏。保持图片补全、覆盖检查、原文保留与取消能力。
- 导入显示实际阶段和页/块计数。总量未知阶段使用不定进度，不编造全流程百分比或剩余时间；以数据库提交为完成边界。
- 以本地原创论文进行 Release 测量，区分文件读取、WebKit 首屏、就绪滚动及导入处理。目标首屏 100 ms、就绪页面 16 ms；设备实测不能替代任意设备保证，WebKit 冷启动单独报告。
- 检查资源去重、HTML/SVG/公式呈现、无外部请求、引用/高亮/书签稳定、失败恢复及迁移；执行 Mac/iPad 构建。iPad 触控帧率与未来手写层另需真机验证。
