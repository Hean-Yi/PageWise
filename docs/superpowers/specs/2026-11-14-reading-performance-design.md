# 连续阅读、最终文档与导入性能

用户确认：已入库论文打开及连续滚动要达到毫秒级体验，不逐页翻动；首次导入可等待，但显示实际阶段和进度。重排结果持久保存，不能每次打开重新组合；同时减少导入开销与冗余存储。

## 实现约束

- 已完成重排收敛为一份可直接打开的最终 PDF，加一份不可覆盖的原始 PDF。正文、译文、来源、稳定页 ID 与批注元数据保留；不额外保存整篇 HTML、图片副本或长期显示缓存。
- 合并只改变文件容器，不重新排版。通过 PDFKit 复制页并序列化生成独立文档；发布前逐页验证文字、字符坐标、页面框、旋转及批注。未通过不替换旧文件，明确提示。
- PageArtifact 增加可选文档内页码；旧数据默认为独立文件第 0 页。显式快照升级，页 ID 与批注坐标不变。
- 先写完整最终文档，再提交数据库路径，再删除被替代分片。失败/取消保留已发布内容；启动清理未提交成品与遗留分片。收敛过程短暂占用新旧两份空间是事务恢复要求，并非长期缓存。
- 阅读器直接打开单一最终文档，保持原生纵向连续滚动，去掉页间装饰间隔。正在阅读时的容器替换不重置视图、选区或滚动位置；固定页内部几何不变。尚在翻译的分片已持久化，继续逐批发布；完整后只收敛一次，避免每批重写全篇。
- 旧完整论文在后台一次性收敛；首次升级前未收敛的旧分片仍可读取，不谎称其首开已达到性能目标。
- 导入先验证结构化内容，通过后跳过无用的 PDF 分栏重排。必须保留覆盖检查、图片补全、复杂页保留和取消能力。已确定保留原版的复杂页不再计算分栏。
- 导入显示阶段及页/块处理计数；下载或读文件等总量未知阶段使用不定进度，不编造剩余时间或全流程百分比。完成以数据库提交为准。

## 验证

以本地原创论文比较优化前后的 Release 测量，分别记录打开准备、首屏绘制、就绪页读取、导入及裁剪，不能用内存命中冒充冷启动或实际滚动帧率。目标首屏 100 ms、就绪页面 16 ms；当前设备实测不替代任意设备保证。验证像素/选文/定位不变、原文件不变、事务失败恢复、旧快照迁移和单套最终文件；运行 Mac/iPad 构建。实际 iPad 触控帧率需真机验收。
