# 结构化重排与单一结果保留

日期：2026-11-14。用户已同意 HTML 优先的重排方向，并要求每篇只保留原始 PDF 与一份最终重排结果。本文件细化本轮本地实现与验收边界。

## 用户已确认的行为

- arXiv 导入优先利用同版本 HTML，原始 PDF 永久保留并可切换查看。
- 新导入不再另外生成一套英文预览页；双语页逐步追加，构成唯一重排结果。
- 已发布页面不原地改变。HTML、网络下载副本和排版临时文件不作为长期缓存保留。
- 正文索引、译文、来源标识、恢复进度与批注是必要数据，不属于可随意删除的缓存。

## 本轮设计决策

arXiv 只对明确带版本号的候选获取 HTML；请求地址、响应地址与版本一致。HTML 不可用、资源不完整或结构无法保留时回退 PDF 路径，不阻止原始论文入库。用户自行上传的 PDF 不自动上传或用标题匹配其他版本。

HTML 转为有稳定 ID 的块，保留段落、标题、列表、图表和 MathML。只保留允许的元素与属性，图片通过受限下载转为内嵌资源；禁止论文脚本、外部样式、活动内容与任意网络请求。应用自带模板用 WebKit 显式分栏分页并导出固定 PDF。正文可选中。数学片段用占位标识保护，译文必须保留标识才可发布。不支持的元素和超出版面的内容明确失败，不能截断后宣称成功。

HTML 与 PDF 的位置通过文字唯一匹配建立。不能确认的原文页不猜测；重排块仍可定位，切换原版时提示需要核对。每个最终页记录真实包含的块 ID。

上传 PDF 走设备本地文字与布局分析：可靠的文字页重排；复杂图表、公式和无法保证阅读顺序的页整体保留原页面几何，与其他重排页组成同一结果。扫描件先回退原版；本轮不承诺 OCR 或任意复杂页面内部重建。局部图表裁剪只有在边界、完整性与阅读顺序得到验证后才能扩大支持范围。

## 存储与恢复

新论文只有 original.pdf 与一组 translated 固定页。HTML 下载在内存中处理；规范化块中暂存的富内容只服务尚未完成的排版，成功提交对应页面后清除。文本和译文索引用于搜索、问答与笔记，继续保留。发布失败删除本次未提交页面，已发布页和完成译文保留以便重试。

启动只清理明确属于本应用、没有被已提交记录引用的排版临时文件。已有旧英文页不自动删除：其可能带有笔迹、书签或外部引用，本轮保留旧记录兼容。新导入不再产生此类额外版本。

## 验收

- 原创 HTML fixture 覆盖段落、MathML、表格、图片、恶意内容、缺资源和版本不一致；不调用真实模型。
- 原创 PDF 验证文字页重排、复杂页视觉保留、扫描页回退与原始文件字节不变。
- 双语页完成后没有英文预览、原始 HTML 和未引用页面；重启恢复不重复发布。
- 固定页追加后旧页面字节与批注 ID 不变；HTML 不可靠页码不得出现在引用中。
- 执行 Swift 格式、测试、原创冒烟与 Mac/iPad 模拟器构建；视觉检查单独报告，不将编译成功描述为真机验收。
