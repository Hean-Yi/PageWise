# SVG 与论文图片呈现

日期：2026-11-14。用户明确要求支持论文中的 SVG，并完整考虑图片来源、格式与呈现。此前只允许 PNG/JPEG 的图片路径由本设计替代。

## 处理契约

- SVG 支持外链 img、object/embed 和内嵌 svg。保留静态路径、文字、变换、渐变、裁剪、遮罩、内部 use 引用和样式；移除脚本、事件和动态行为。以隔离的图片上下文交给 WebKit，禁止未本地化的外部请求。
- SVG 内文字保持原样，不翻译；图注随正文翻译。SVG 文本与导出器字形标记只用于本地覆盖检查，不成为正文、翻译输入或引用证据。
- SVG 内依赖的图片按同一版本来源规则获取并内嵌，限制深度与总资源量。未知或不能保留的结构只影响该图片，不因此拒绝整篇 HTML。
- 位图按实际内容解码，覆盖系统 ImageIO 能解码的 PNG/JPEG/WebP/GIF/TIFF/HEIF/BMP 等；校正 EXIF 方向、保留 alpha，必要时转换为兼容 PNG。尺寸与资源预算用于避免耗尽 iPad 内存。
- 多页 PDF/TIFF 图片不能悄悄只保留第一页；在预算内逐页呈现。动态图使用首帧并明确记录静态呈现提示。EPS/PS 等无法在两端安全解码的资源走局部原版保留，不执行外部程序。
- 图片与图注一起形成内容块，保持顺序、宽高比，不裁剪。宽图和长图使用独立且可缩放的固定页，避免强制压到普通正文大小。多面板图按来源顺序保留。
- 无法解析或下载的图片显示明确占位说明；若图注可唯一定位原 PDF 页，改为保留该原页。没有可靠映射时，不猜测原页位置。正文和其他图片继续处理。
- 最终仍只保留原始 PDF 与一套固定页；图片中间资源在对应固定页提交后释放，既有固定页不重新生成。

## 验证

原创样例覆盖三种 SVG 嵌入方式、路径与 use、渐变、裁剪、透明度、文字、内部图片、方向修正、动图/多页资源，以及损坏、缺失和不可信引用。验证 SVG 输出是否保持矢量，宽/长图与图注是否完整，局部图片失败不会丢失正文或让整篇退回。

以公开 arXiv HTML 做独立真实兼容性探测，资料只放忽略目录或内存，不提交外部论文。默认测试不联网，不调用真实模型。执行完整格式、自动化测试、原创视觉冒烟与 Mac/iPad 构建；区分图片转换成功、完整论文排版与真实模型翻译验证。
