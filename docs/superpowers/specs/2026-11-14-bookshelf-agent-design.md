# 封面书架与书库 Agent

本轮直接落实用户提供的 PaperReader / Apple Books 截图与明确交互要求。沿用原生 SwiftUI、macOS 15 / iPadOS 18、本地存储及已发布页面不变的约束。参考 Claude 的留白、浅边框工具卡和紧凑操作，不复制品牌素材。

## 已确认的页面方向

- 书库默认使用大封面网格。统一竖版比例，论文标题直接排在封面上；不虚构作者、出版信息或封面图片。
- 全部论文和收藏的网格首位为虚线加号，已读集合不显示添加格，侧栏不再提供“正在阅读”入口。点击打开在线论文查找。默认仅加号；用户追加要求悬停时加号上移，并淡入两行“拖拽 PDF 至此 / 或点击在线查找”，键盘聚焦等价，减少动态效果时立即切换。全部论文空库同样显示这个入口。继续支持全窗口 PDF 拖放，左下保留“导入 PDF”。移除主内容添加菜单和右上加号。
- 保留继续阅读，降低其高度，为封面腾出空间。集合、搜索和排序保留，取消列表/卡片切换以统一书架体验。
- 悬停封面轻微抬升，阴影加深；显露收藏与更多操作。键盘焦点提供同等操作；iPad 通过长按菜单访问收藏和状态，不依赖悬停。系统减少动态效果时关闭位移动画。
- 右上为 Agent，点击打开右侧面板；窄窗口/iPad 紧凑宽度使用浮层。关闭面板不清空会话，单独提供新对话操作。

## 本轮实现选择

封面为代码绘制的素色书封：稳定的配色、书脊、细边缘、衬线标题，避免随机变化与无关装饰。较长标题允许多行并适度缩小；完整标题始终可通过辅助功能及提示读取。用户在预览后进一步要求封面下方默认完全留白；收藏与更多菜单仅悬停/聚焦时显露；进度移到封面右上角常驻的细圆环。悬停栏保留固定空间，不推动相邻内容。圆环沿用封面文字颜色，未开始为空环、已读为完整圆环与勾号，无法定位的历史进度为虚线环；不显示虚假的百分比。进度变化有短过渡，遵循减少动态效果。封面提示与辅助功能继续提供进度描述。“继续阅读”中的微型缩略图不增加圆环，避免过小的装饰。

进度按保存位置对应的原始来源页 / 原文总页数计算，固定页通过稳定页面 ID 解析；缺失位置显示“未开始”或“在读”，不猜测。用户追加确认：进度到 100% 自动视为已读，正在阅读集合排除这些论文；全部论文始终先展示未读完的论文，再展示已读论文，每组内部遵循所选排序。旧资料保存的 100% 位置同样生效，侧栏计数与书架保持一致。达到末页时保存已读状态，回看前页不自动撤销已读；仍允许主动标记未读。

书库 Agent 与当前论文助读分开：前者跨库查找与执行导航，后者继续以当前论文为主要证据。若从阅读页打开书库 Agent，已有论文助读面板收起，避免双重侧栏。

## Agent 能力与交互

采用实际 Chat Completions `tools` / `tool_calls` / `tool_call_id` 往返协议，复用用户设置中的 GLM 或兼容接口与 Keychain。依据[智谱工具调用文档](https://docs.bigmodel.cn/cn/guide/capabilities/function-calling)，使用 `tool_choice: auto`。模型必须支持工具调用；错误清楚呈现，不伪造已执行结果。

| 工具 | 行为 | 可见结果 |
| --- | --- | --- |
| search_library | 按标题和正文关键词检索本地库，支持模型改写双语查询；只返回真实命中 | 在过程中列出命中，返回论文与摘录的结果编号 |
| read_paper | 读取已检索论文的指定原文页，补足上下文；标注无可提取文字 | 在过程中列出所在页的证据 |
| search_online | 使用 arXiv 检索验证过的候选，标题/作者/年份/来源来自响应 | 在过程中列出候选，返回可选用的结果编号 |
| prepare_import | 从本会话已有的候选 ID 创建导入请求，不接受模型生成 URL | “下载并导入”按钮，点击后下载、解析、去重并显示结果 |
| open_paper | 从当前会话已提供的本地论文/证据 ID 生成导航目标 | “打开论文”或“前往第 N 页”卡，用户点击执行 |
| present_results | 按顺序选择已登记的结果，可附推荐或引用理由 | 每项一张卡，重复来源合并 |
| create_reading_note | 读者明确要求写入时，以同篇论文的已登记本地摘录和逐字引文一次提交笔记与标画 | 点击已保存笔记可打开原文和现有笔记编辑器 |
| ask_user | 需要读者澄清范围时提出一个问题和二至四个选项，暂停工具循环 | 点选即回复，也可在输入框填写自己的答案 |

执行时在无卡片边框的过程区显示工具、状态和数量，完成后收起步骤。展开检索行可核对全部返回的候选。模型在工具前发送的公开进展保留在时间线中。官方 DeepSeek 接口返回可显示的思考文本时，单独保留预览，可展开全文。

回答下方的圆角卡只展示选中的结果，保留推荐顺序、可选理由与可操作的来源。卡片上的追问按钮将单项来源带入输入框，读者可以编辑问题或移除来源，再发送。回答共用笔记的离线 Markdown 和 KaTeX 引擎，论文正文中的引用编号绑定当前回答登记的证据。用户以自然语言要求跳转时也提供导航卡。定位使用已登记的 ID 和合法页码。

下载新论文直接在线查找，再用命中的候选生成导入卡。每张在线推荐卡直接提供“下载并导入”。按钮使用该卡已核验的候选启动下载、解析、去重和入库，点击过程无需模型参与。连续点选的论文按点击顺序处理，每张卡可取消或重试。完成后主按钮变为“在书库打开”。查自己的论文或读书笔记时，分别使用书库检索或笔记检索。读者要求“书库没有再下载”时按指定顺序查找。可用现有对话回答的问题可直接作答。模型在原有请求中选择工具，无需单独调用模型判断意图。

每轮随请求提供当前可用的工具定义。有在线候选后才提供准备导入，有本地论文编号后才提供读取和定位，有结果卡后才提供展示结果。写笔记和精读要有本轮委托及所需的原文摘录或论文编号。

侧栏随滚动加载问题、回答和单张结果卡。单段纯文本用原生文字显示，公式和排版内容按需渲染；返回旧回答时可复用已测得的高度。模型持续输出时合并短时间内的草稿刷新，结束时显示完整回答。开始等待澄清时，让选项进入视口；读者已主动上滚时保留其位置。

每个问题默认有 16 轮可用工具、48 次调用。同一回复可以提出多项调用，每项占一次额度。每轮模型请求都包含总额和余额，提醒模型为选择推荐卡、提交笔记等收尾步骤预留额度。工具用尽时再给模型一次只作答的机会。超出剩余额度的整批调用跳过，模型用已有证据收尾。仍检查参数长度、结果数量、上下文容量、工具名、ID 和页码。候选资料和正文是证据，不能成为应用命令。导入只由用户点击可信候选卡触发，不允许任意文件路径、任意 URL、代码执行、未经读者委托的笔记写入或删除。

书架检索和助理在线检索共享题名查询缓存。DataCite 和 arXiv Atom 分别排队，耗时的版本查询不会阻塞另一来源上的题名检索。题名查询先向 DataCite 的公开 DOI 索引发送关键词，限定 arXiv 前缀并核对返回记录的官方论文地址。登记版本可定位时直接使用对应版本。索引无匹配或不可用时再查 arXiv Atom。Atom 查询串行，两次开始至少间隔三秒。首次 429 即进入冷却，两处索引各自记录等待期限。冷却中跳过的 Atom 请求单独说明。模型能区分查询失败和成功零命中，只有修正关键词可能有帮助时才建议改写。请求频率依据 [arXiv API 使用条款](https://info.arxiv.org/help/api/tou.html)。

MVP 的书库 Agent 会话仅保留在本次运行内；关闭侧栏保留，重新启动或新对话清空。既有论文聊天、记忆和 Obsidian 规则不变。进行中的请求可取消；新会话不会收到旧请求结果。取消不声明服务端未计费，默认不自动重试。

## 验证与交付

使用原创 PDF 与假模型/检索服务验证：协议往返、工具结果追踪、未知工具/伪造 ID 拒绝、导入点击前零下载、重复点击不重复导入、取消无迟到写入、无结果、精确来源页导航、进度稳定映射。UI 检查空库/单篇/多篇、长标题、悬停、收藏、继续阅读、查找入口、Agent 开关及窄窗口。运行 Swift 测试、离线 PDF 冒烟、Mac 和 iPad 构建；真实 GLM / 外网下载 / Pencil 真机不包含在默认验证。每个完成的逻辑改动单独本地 commit，不推送。
