# AI 精读与书库笔记引用

## 阅读路径

打开一篇论文，在右侧「论文助读」点「AI 精读」。也可直接说“精读这篇论文，重点看消融实验”。助读沿用翻译服务配置，显示读取和分析进度，读者可取消。完成后可打开「文末总结」和可展开的「段落批注」。点「查看精读」会打开已保存的文末总结。点旁边的「重新精读」可生成新的分析。精读笔记和手写的阅读笔记使用相同的编辑、定位和删除入口。

全文骨架按「问题 → 论点 → 证据 → 反驳 → 结论」组织。每一环都能点开支持它的本篇引文。只写有可核对引文的环节，未找到依据或引文定位失败的情况记入覆盖说明。段落批注紧扣具体措辞、比较、指标或假设，解释它对作者推断的影响。全文总结拥有独立笔记身份，引用支持论证的原文。源码阅读在最后一个已发布段落后呈现总结，原版 PDF 和重排都从目录末尾进入总结页。版本升级按已保存报告中的笔记 ID 归置旧总结，保留原 Markdown 和引文。

| 颜色 | 分析维度 | 选点依据 |
| --- | --- | --- |
| 黄色 | 核心论点 | 作者希望读者接受的主张或关键推断 |
| 红色 | 关键概念与术语 | 一个定义如何改变问题的边界或指标的含义 |
| 蓝色 | 实证证据与数据 | 能检验某一步推断的实验比较、表格或观测 |
| 绿色 | 让步与反驳 | 作者主动承认的局限或对异议的回应 |
| 紫色 | 方法论 | 实验设计、对照或分析方法如何影响可得结论 |

批注列表同时显示颜色和维度名称。作者没有回应的质疑记在对应段落的审读意见里。每次精读按实际内容选点，各色数量随论文而定。已存在的读者标画保留原来的样式。

## 精读提示词

分段分析使用当前窗口的正文、可定位的图表题注、可核实的表格行列，以及按当前段落主题检索到的其他论文阅读笔记。模型先找改变判断的转折，再写段落角色、通俗解释和独立评议。实验批注要指出比较对象、条件、指标含义和数据允许的推断。如果两个系统同时改变了策略和计算预算，结论应限定在所比较的配置，并指出区分两种解释所需的对照。只有文章提供了相关事实，才能使用这个判断。

通过本地核对的段落批注、原文摘录和相关表格行进入独立的文末写作请求。单个窗口的论文也经过这一步。模型按论文自身的问题写标题和小节，解释具体机制、核对关键证据，并指出尚不能判定的原因。每节随文登记引用，跨论文比较取自已经保存的本地笔记。数值无法从所引材料核对时，应用会针对这些小节请求一次订正；精读结果标出被省略的内容。模型达到输出长度上限时单独报告，完整写作仍失败时保留已经核对的分段解读及出处。读者可将同一份写作提示词连同其他论文提供给自己的模型。[文末笔记提示词](../../../Sources/PaperReaderKit/Resources/Prompts/CloseReadingNotebook.md) · [分段批注提示词](../../../Sources/PaperReaderKit/Infrastructure/Models/CloseReadingPrompts.swift)

文末笔记使用正文的阅读栏和中文字体，支持 Markdown 层级、列表、引语和公式。进入笔记编辑器可以继续修改。重新精读生成新结果，之前写下或修改的内容仍可找回。

## 可核对的范围

- 完整且可用的已发布源码按稳定内容块读取。正在生成的源码版优先使用完整的本地原版 PDF。长文按窗口处理，超出预算时在全文位置间隔取样，结果列出检查覆盖范围。
- 源码版精读可引用已发布的独立公式和含运算的行内式。模型得到公式对象保存的 TeX 或替代描述，引用由应用定位到原语言对象。同一段重复且无法区分的公式，以及仅有排版字形的公式，不作为独立的数学依据。
- 图表优先读取能对齐的表头、行名、数据和单位；只核实部分列时，仅分析这些列。无法还原的图表仅依据题注与正文，不能据此读取曲线坐标、误差棒或未报告数值。无法定位正文的扫描页计入覆盖说明。
- 精读批注定位在当前论文的原句旁，论证骨架可回查本篇依据。跨论文比较来自书库中已经保存的笔记，模型可据此回忆先前的观察和疑问，并标明是笔记中的判断。
- 笔记编辑器的链接按钮打开「引用阅读笔记」。读者按正文关键词或论文名搜索，选择一条即可插入。点击链接可预览目标笔记的最新内容，再打开这条笔记。以前创建的原文链接仍可读取。
- 书库 Agent 可按主题搜索阅读笔记，论文助读按问题和选区召回，精读按各组段落召回。设备上的词项倒排索引将长笔记分段，按匹配词的稀有程度、正文和论文标题排序。索引按需从已保存的笔记构建，新增或修改的内容在下一次查询生效，删除的笔记退出结果。书库里的论文原文不进入笔记索引。
- Agent 写入跨论文链接时，应用核对检索编号、目标笔记和摘录。保存后链接跟随笔记身份；内容调整后预览显示新版本，删除后提示笔记已不可用。
- 标画、批注、骨架和完成记录一起保存。取消或写入失败时不会遗留半套批注。已保存的精读可离线打开，后续人工编辑受保留。
