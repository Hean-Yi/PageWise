# AI 精读与本地原文链接

## 阅读路径

打开一篇论文，在右侧「论文助读」点「AI 精读」。也可直接说“精读这篇论文，重点看消融实验”。助读沿用翻译服务配置，显示读取和分析进度，读者可取消。完成后出现「全文论证骨架」和可展开的「段落批注」。再次点「查看精读」可打开已保存的结果。精读笔记和手写的阅读笔记使用相同的编辑、定位和删除入口。

全文骨架按「问题 → 论点 → 证据 → 反驳 → 结论」组织。每一环都能点开支持它的本篇引文。已读材料没有提供依据时，该环显示缺口。段落旁的短笔记解释这一段承担什么角色、用日常语言重述其意思，再提出对推理最有影响的一条审读意见。

| 颜色 | 分析维度 | 选点依据 |
| --- | --- | --- |
| 黄色 | 核心论点 | 作者希望读者接受的主张或关键推断 |
| 红色 | 关键概念与术语 | 一个定义如何改变问题的边界或指标的含义 |
| 蓝色 | 实证证据与数据 | 能检验某一步推断的实验比较、表格或观测 |
| 绿色 | 让步与反驳 | 作者主动承认的局限或对异议的回应 |
| 紫色 | 方法论 | 实验设计、对照或分析方法如何影响可得结论 |

批注列表同时显示颜色和维度名称。作者没有回应的质疑记在对应段落的审读意见里。每次精读按实际内容选点，各色数量随论文而定。已存在的读者标画保留原来的样式。

## 精读提示词

分段分析使用当前窗口的正文、可定位的图表题注、可核实的表格行列，以及少量相关本地论文片段。模型先找改变判断的转折，再写段落角色、通俗解释和独立评议。实验批注要指出比较对象、条件、指标含义和数据允许的推断。如果两个系统同时改变了策略和计算预算，结论应限定在所比较的配置，并指出区分两种解释所需的对照。只有文章提供了相关事实，才能使用这个判断。

归纳阶段根据已核对的候选批注和论证引文选择关键节点。优先保留关键实验、相互矛盾的观测和作者实际处理的异议。同一结论在摘要和讨论中重复时，优先保留可以检验它的位置。提示词与模型调用分开维护。[精读提示词](../../../Sources/PaperReaderKit/Infrastructure/Models/CloseReadingPrompts.swift)

## 可核对的范围

- 完整且可用的已发布源码按稳定内容块读取。正在生成的源码版优先使用完整的本地原版 PDF。长文按窗口处理，超出预算时在全文位置间隔取样，结果列出检查覆盖范围。
- 图表优先读取能对齐的表头、行名、数据和单位；只核实部分列时，仅分析这些列。无法还原的图表仅依据题注与正文，不能据此读取曲线坐标、误差棒或未报告数值。无法定位正文的扫描页计入覆盖说明。
- 每条批注的主锚点须在本篇逐字核对。其他本地论文可以提供对照、补充或反例。引用按书库论文、文件摘要、内容版本和具体文字范围登记。点击先预览片段及上下文，再点「打开原文」切换到对应位置。移除论文或失去匹配版本后提示读者。
- 读者在 Markdown 笔记编辑器点击链接按钮，选择书库论文和片段即可插入原文链接。Agent 通过同一接口写链接，须先取得本地原文和可定位引文。输入网址、书目题名或模型生成的坐标不能登记为原文片段。
- 标画、批注、骨架和完成记录一起保存。取消或写入失败时不会遗留半套批注。已保存的精读可离线打开，后续人工编辑受保留。
