# 可配置模型服务与设置视觉

范围：落实用户已确认的自带 API 配置和本轮设置页优化，不改变论文阅读、固定页及本地优先约束。

## 交互与视觉

- 设置分为「模型服务」和「笔记与存储」。宽窗口左侧切换分类，窄窗口使用顶部分段控件。底部固定显示操作，配色、标题和留白与书库及阅读器一致。视觉参考 [Claude 产品页](https://claude.com/product/overview)。
- 服务预设包括 OpenAI、Anthropic Claude、Google Gemini、DeepSeek、千问、Kimi、智谱 GLM、Mistral AI、xAI Grok、火山方舟（豆包），另有「自定义兼容接口」。预设填写官方基础地址和建议的模型 ID，模型可按账户权限修改。自定义服务支持手填请求地址。
- API 地址、模型、API Key 都可编辑。地址接受 HTTPS 基础地址或完整 chat/completions 地址，并规范化，避免重复追加路径。
- 密钥只显示已保存 / 未配置状态，不回填明文。留空复用当前地址的密钥；地址改变时不把旧密钥发送到新地址。
- 表单编辑使用草稿；取消不改变活动配置。保存验证后才生效，失败显示在设置内并保留草稿。
- 测试连接由用户主动触发，使用草稿和一条固定短消息，不发送论文或笔记；明确提示可能消耗额度，测试不保存配置。
- 移除密钥先作为草稿操作，保存时解除绑定并清理 Keychain；不能把移除动作藏在本地存储说明中。
- Obsidian 目录选择为独立操作，系统确认选择后立即授权，表单中明确说明。原有手动写入规则不变。

## 实现边界

ModelSettings 负责规范化和校验；ModelConfigurationStore 负责配置文件与 Keychain 提交；ReaderModel 协调用例，View 只编辑草稿和显示结果。

每次新密钥先写入独立 Keychain 账户，再原子提交不含密钥的设置文件。文件写失败时移除新账户，活动配置仍指向旧账户；成功后清理旧账户。旧 JSON 没有 credentialID 时按旧账户读取，下一次更换或移除时迁移。若清理失败，明确提示，不宣称钥匙串已删除。

设备一次保存一套活动配置。更换配置时，进行中的重排翻译保存已有进度，后续请求使用新设置。已发布页面和已保存译句仍可阅读。

连接测试、问答、翻译和书库助理共用 Chat Completions 请求构造。对不同服务分别处理采样参数、输出额度和 JSON 模式。Claude 使用官方兼容接口，结构化译文继续由应用校验；Gemini 工具调用的签名随同一模型的后续请求回传。更换服务、模型或凭据时，书库助理使用新的请求上下文，界面上的历史对话仍可读。[Claude 兼容接口](https://platform.claude.com/docs/en/cli-sdks-libraries/libraries/openai-sdk) · [Gemini 兼容接口](https://ai.google.dev/gemini-api/docs/openai)

## 验证

测试地址规范化、拒绝不安全 URL、旧配置兼容、换地址不复用密钥、配置提交失败保留旧配置、清除和替换密钥、测试请求不携带资料且不保存草稿。通过 Computer Use 检查真实设置页、取消与重新打开、错误提示及示例阅读布局。真实密钥和网络验证由用户主动进行。

参考：[智谱兼容接口](https://docs.bigmodel.cn/cn/guide/develop/openai/introduction)、[SwiftUI SecureField](https://developer.apple.com/documentation/swiftui/securefield)。

## 2026-11-14 用户补充：整体 UI / UX

用户明确要求整个应用以视觉引导、极少文字呈现主次。此次实现扩展到全局界面：

- 书库：侧栏导航、论文卡片；空态仅保留导入、查找、示例。启动进入书库。
- 阅读：正文居中且限制可读宽度；原文 / 重排 / 双语三态；讨论按需展开，选文后出现高亮 / 解释。
- 讨论：三个简短问题入口，输入框固定底部，引用收起；不默认占据正文空间。
- 日历：月份网格、阅读日标记、大数字统计和时间线；记忆与搜索沿用浅卡片和同一配色。
- 视觉：暖灰底、墨色正文、低饱和青绿强调，适配系统深浅色；删除重复口号、技术承诺与常驻状态条。
- 新生成的重排页移除逐段语言标签，以字体颜色、译文缩进和细线区分。既有发布页面仍不修改。

原生 UI 验收使用 Computer Use 与原创示例；不发送论文到外部模型。
