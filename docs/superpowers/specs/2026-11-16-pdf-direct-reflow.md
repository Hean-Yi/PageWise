# PDF 直读与渐进重排

日期：2026-11-16。用户确认：已有 PDF 不查询 HTML，本地无法确定的结构交给模型，优化等待和整页图片回退。本节取代旧方案对新重排入口的 HTML 优先和完整提取要求。

## 实现

```text
Stored PDF -> hash check -> page 1 evidence -> model plan + translation -> reader
                                |                       |
                                +-- saved page cursor --+-> next page
```

- 提取 actor 在本次任务内复用 PDFDocument，不经过 PDFImporter，不生成第二份原文件，也不请求 HTML。保留完整文件哈希核对，不省略身份验证。
- 每批一页；模型流式返回完整块后保存并展示，再处理下一页。正文高度达到 `min(240, max(120, viewportHeight * 0.4))` 且可见资源就绪即可进入阅读，不再等待 1.5 屏正文。
- PDFKit 字体片段先在视觉行内合并再判断栏；多标签行只产生局部标签/异常字符种子，不直接生成全行宽裁图。图表/公式的裁剪只扩展到相交文字，不把整个横带与另一栏正文一并裁掉。裁图合并至互不重叠，文字覆盖计数必须一致。支持的文本层页先提取，不执行重复 OCR。
- 本地为每页证据提供来源 ID、原文、归一化矩形和待定顺序组。模型可在同组内排序并整理段落/标题。作者、机构和通讯信息作为 front_matter 排除；确认无关的页边标记和装饰标志作为 non_content 排除。二者不发布 HTML、不翻译，excludedSourceIDs 记录处置，原 PDF 和来源正文完整保留。参考文献和代码保留原文、不翻译。全部来源仍恰好使用一次，组间不可移动；模型不直接生成 HTML，不改写英文证据。
- 扫描页沿用设备端 OCR。高置信度正文可与局部图形并存并交给模型决定顺序。低置信度或缺失文字、公式保留局部原图；无法分离时保留整页并告知用户。
- 游标和来源同时保存，暂停恢复复用同一批证据和已接受计划。换模型只处理尚未发布来源，旧阅读版式和批注保留。
- 局部图片按 PDF 原尺寸的 1.5 倍设置显示宽度，并限制不超出容器，不再把细小页边文字或标志撑满整屏。已有发布 HTML 不原地更改。

## 边界

这些变化不意味着模型能恢复没有证据的文字。当前自动请求仍以文字、坐标和对象引用为输入；困难局部图像的自动视觉模型识别尚未接入。旋转、原有交互批注、文字编码损坏、超出证据预算或不可可靠识别的扫描件仍可能回退。旧 HTML 解析与旧区域修复入口继续保留兼容行为，不回写已有版式。

页内证据组成完整结构计划，单次最多生成两块正文译文，短标题与非翻译块不计。新文本来源按行距、缩进与字号组织自然段，不再按 1200 字符硬切分；合并段落不再以 1600 UTF-16 单元为拒绝条件。控制每次处理的完整段落数量，保留总输入与响应大小边界。响应通过 window_pause 正常结束，下一请求以 window_resume 引用已保存计划，不重复输出整份计划。复用同一 ModelClient/URLSession，保持阅读任务连续；底层连接是否复用由系统和服务端协商，不承诺一条永不关闭的 HTTP 流。

若服务仍返回 length，已完成块保留并自动续接；有进度时继续，无进度最多续接两次、降为单正文块并有界增加输出预算。连续无进展才告知用户暂停，鉴权和网络错误不盲目重试。草稿不作为完整段落保存。本文不承诺任意论文的成功率，也不把本地 fixture 耗时当作真实 API 速度。

正式计划只要求模型输出 kind 与 source_ids，本地派生块编号、完整范围及对象引用；纯文字原文不再在 translation_parts 中重复发送。模型可合并同组纯文字作者信息或标题，完整覆盖校验保留。原生裁图可由模型区分 figure/table/display_formula，但像素和对象归属不变。

事件协议校验失败后切换 AIReflowRecovery：已有计划只逐段请求纯译文；未有计划则单独请求简化 blocks 规划，仍经完整覆盖、顺序和对象校验后保存。每个翻译请求对应一个完整段落，正常结束且公式标记验证后才发布；length 半段不发布，原已完成前缀不重写。有进展重置失败计数，连续无进展有界恢复后如实暂停，内部字段诊断仅记元数据，不记录原文或密钥。不用无限重试或隐藏失败冒充成功。

正式请求使用 s0/s1 等短来源标识，本地映射回稳定 UUID。首事件验证版本、请求与窗口身份后，后续事件只需序号、类型和载荷；完成/暂停无需模型重复计算总块数，本地以完整计划和提交游标核验。旧完整事件格式仍接受，错误身份、越序、重复来源和提前结束仍拒绝。该精简只减少输出开销，不放松来源或恢复校验。

## 验证

本地生成 PDF / 扫描 fixture 覆盖双栏中间公式、图形与正文分离、来源字符覆盖、首批仅一页、无 HTML 探测和重复导入、原文件哈希、组内排序与跨组拒绝、首段发布先于后页解析、持久化游标恢复和不重复发布。实际执行结果记录在 MVP 状态中。

最终版本按用户最新指示只做自动化回归和构建，不自行做视觉验收。原始 PDF 与旧版式保留；段落和裁剪修复需要重新生成一个新阅读版本才能应用，继续旧任务不会修改已发布片段。
