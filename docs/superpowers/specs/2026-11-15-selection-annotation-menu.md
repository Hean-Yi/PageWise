# HTML 选区批注浮层

用户已明确批准菜单结构与行为，本轮直接实现当前 HTML 连续阅读器：松开选文自动在选区附近显示应用暖色浮层，避开窗口边缘；第一行八个颜色，选中项有更深背景与边框；第二行高亮/下划线；第三行添加书签；第四行添加笔记禁用占位。完整已标注选区附取消按钮。点击颜色或模式立即保存并显示结果，保留浮层以便继续修改；点击外部或 Escape 收起。聊天选文仍保留独立语言过滤。

标注按论文、内容块、语言/共享对象、UTF-16 范围保存可选颜色与样式字段，旧记录默认黄色高亮。新操作先从重叠旧区间减去所选范围，再添加新标注；未选部分保留原色和样式，部分取消同理。对象作为整体，不拆图或公式。旧 DOM/联动坐标由实际文档校验并投影到独立语言范围，仅在用户编辑命中旧记录时显式拆分，投影失败拒绝该编辑而不删除旧记录。书签锚定选区第一块，重复添加不删除；笔记不产生记录或调用模型。

平台脚本负责选择几何、浮层交互、坐标投影和 CSS 显示；Swift 领域算法负责范围相减，应用层负责动作及持久化。菜单和标注不能修改正文几何或覆盖原 PDF。旧 PDF 控件保留，本次浮层服务于 HTML 连续阅读。测试覆盖部分覆盖/取消、混合标注、多段与中英文隔离、共享对象、旧坐标兼容、重开恢复及书签幂等；先构建 Mac 再以 Computer Use 检查实际窗口。

## 用户验收修正：选区持续可见与字符范围

用户于本轮明确要求：临时选区采用半透明深灰叠加在已有高光之上，避免与蓝色高光混淆；应用颜色、切换模式或取消标注均保留选区，点击正文其他位置再清除。中英文独立标画后不再限制完整单词，英文与中文都按实际字符范围保存、覆盖和取消。共享对象仍为整体。实现保留原生范围和语言过滤，选区绘制优先级高于保存标注，不改变正文节点与布局。回归覆盖单词局部、句尾半词、标注前后选区保留、覆盖层优先级和外部点击清除；构建后在真实 Mac 窗口验证叠色与连续操作。
