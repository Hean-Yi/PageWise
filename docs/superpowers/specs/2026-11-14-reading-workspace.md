# 书库与阅读工作台优化

本轮来源：用户明确要求学习 NeoRead 的设计风格和功能，并优化现有应用。既有需求与数据不变量继续生效；下面是本轮实现选择，不将参考项目的能力视为 PaperReader 已实现。

## 参考与取舍

研究了 [NeoRead](https://github.com/cynicalight/NeoRead/tree/efd3a9a) 的 README、仓库内 `website/assets/screenshots/library-light.webp`、`pdf-light.webp`、`pdf-bilingual-ai.webp`，以及 `apps/web/src/papers/PaperLibrary.tsx`、`ReaderView.tsx`。参考版本为 `efd3a9a`。这是截图与源码分析，未运行 NeoRead。

| NeoRead 的交互 | PaperReader 本轮落点 |
| --- | --- |
| 安静的中性色、细边界、明确主次 | 暖白工作面、浅沙色导航、少量赤陶色强调；标题优先，辅助信息降级 |
| 筛选、排序、收藏、不同书库视图 | 本地标题搜索；全部/在读/已读/收藏；最近打开/添加时间/标题排序；列表/卡片切换 |
| 左侧目录，中间正文，右侧 AI/笔记 | 阅读时用目录/查找替换书库导航，右侧助读/笔记可收起，窄窗口使用浮层 |
| 恢复上次阅读位置 | 按论文保存阅读模式、固定页面标识与页码，重新打开继续阅读 |
| 书签、批注回看与定位 | 一键书签；笔记栏集中显示书签和高亮，点击回到对应版式与页面 |
| 多标签、文献元数据、引用导出 | 后续设计候选；本轮不增加不完整入口 |

保留原生 SwiftUI / PDFKit，不引入 NeoRead 的 Electron、Go 或 Node 运行服务。不复制其品牌、源码或截图素材进产品。

用户随后补充参考 Claude 的设计思路和风格。视觉方向据此调整为暖纸色、炭灰文字、柔和赤陶色、衬线内容标题与无衬线操作标签；使用留白和细分隔线，减少嵌套卡片。参考 [Claude 官方产品页](https://claude.com/product/overview) 与 [awesome-design-md 的 Claude 风格条目](https://getdesign.md/claude/design-md)；后者为独立风格摘要，并非 Claude 官方完整设计规范。保留 PaperReader 品牌，不复制 Claude 标识。NeoRead 仍作为阅读工作流的参考。

## 页面与行为

- 书库：侧栏显示集合与数量；顶部本地搜索与添加论文；一条轻量视图工具栏；列表默认突出论文标题、阅读状态、页数和最近打开日期。卡片是可切换视图。收藏与状态操作直接可见或在菜单中。空库继续提供拖入 PDF 与本地原创示例。
- 阅读：目录优先使用 PDF 自带 outline；没有目录时诚实显示“页面”及页面摘录，不虚构章节。文内查找在已提取正文及已完成译文内查找，显示来源页，点击定位当前可用版式；无法定位到当前版式时切回原文并提示。无可提取文字时明确说明。
- 右栏：助读与笔记两个页签；助读保持当前论文证据优先；笔记集中展示书签、文字高亮与论文总结，提供生成总结、保存到 Obsidian，保存讨论仍单独询问。手写仍在固定页内编辑与保存。
- 页码条：前后页、页码跳转、书签；选文时显示高亮和解释。全部图标有 tooltip 和无障碍标签。
- 阅读状态：打开未读论文变为在读；“已读”由用户主动标记，不根据滚动自动判断。阅读位置是最近查看页，不伪称已读百分比。
- 快捷键：书库查找和文内查找分别绑定当前场景的 Command-F，返回书库 Command-Shift-L。

## 数据与边界

新增书库快照 v2，包含每篇论文阅读偏好、位置与稳定页书签；从 v1 显式迁移并保留所有论文、批注、笔记、记忆、阅读事件。未知版本拒绝打开，绝不删库。页面位置以 `pageKey` 为主，页码为辅助；追加双语页不改变已有位置。切换模式按来源页映射，旧版式批注依然绑定旧页。

文内查找来自现有提取文字，不做 OCR、联网搜索或额外模型调用。不对已发布 PDF 改字号、改版式或覆盖文件。不增加 iCloud 同步声明。系统浅色/深色继续适配。

## 验收

自动化覆盖 v1 数据迁移、未知版本保护、阅读模式与位置恢复、书签去重与跨版式定位、过滤排序、原文/译文检索和旧页面不变。完整运行格式、测试、离线冒烟、Mac 与 iPad 构建。Computer Use 检查真实 Mac 窗口中的书库、阅读目录、查找、笔记栏与状态恢复；只用原创示例，不调用真实 API。iPad 真机与 Pencil 仍单独标注未实测。
