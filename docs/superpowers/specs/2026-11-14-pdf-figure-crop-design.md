# 图片失败后的 PDF 像素裁剪

用户确认：图片无法转换时，优先从原始 PDF 裁出图件替代；用简单算法、像素定位确定范围。SVG 图内文字继续保留原样，图注参与翻译。

## 处理流程

1. 从 HTML 保留独立图注及其翻译结构，在 PDF 中唯一匹配图注和源页；不以图编号猜测页码。
2. 在设备上以受限分辨率渲染候选页，建立非背景像素掩码。利用 PDF 文字行坐标区分正文和图内标签，结合留白、连通区域和列边界寻找图注上方的图件；多个面板作为一个整体。
3. 对候选区域检查图注距离、相邻正文、页面边缘、连通区域覆盖和歧义，保留标签和小边距。位置不可靠时保留原页；缺少可靠源页时仍明确提示。
4. 只将可靠区域重新以高清分辨率绘制为兼容图片，替换该图件；图注保持可选文字和双语翻译。原始 PDF 不改动，裁剪中间图片随对应固定页提交一起清除。

## 验收定义

99% 是用户提出的目标，不是当前已验证结果。成功必须同时满足对应图件正确、主体和图内文字完整、没有混入相邻正文；不能把生成了裁剪文件、保留整页或低置信度拒绝算作成功。

默认测试使用原创带真值矩形的 PDF，覆盖单图、双栏、多面板、标签、噪声、相邻正文、错页和无法定位。验证框覆盖、正文排除和最终页面实际渲染；真实 arXiv 用强制图片失败探测，资料仅留本地忽略目录。统计自动裁剪、拒绝和误裁分别报告；在足够且有人工标注的代表性样本验证前，不宣称达到 99%。不调用模型，不引入 Python/Mac 常驻服务。
