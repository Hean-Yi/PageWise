# 主题书架与页内在线查找

用户确认每篇论文只属于一个书架，拖拽表示移动归属。主题书架直接显示在全部论文页，不新增侧栏分类；保留继续阅读、未完成优先、封面悬停操作和 PDF 导入。

全部论文页上方显示主题书架卡片（叠放封面、名称、篇数），旁边提供新建入口，页内输入名称。下方呈现未分类论文及原有虚线加号。选择书架在同一内容区呈现该书架论文，顶部可返回全部论文。拖拽论文到书架卡片移动归属，拖入未分类目标移出；菜单提供相同操作以支持键盘与触摸。书架可改名、删除；删除只解除归属，论文回到未分类。

在线查找通过当前页面内展开搜索区与结果列表，不使用 sheet 或新窗口；书架上下文保留，关闭后恢复。打开时输入自动聚焦，展开/收起使用短淡入位移动画，支持减少动态效果。查询/下载可取消，失败保留结果供重试；新查询或关闭后不能出现过期结果。结果导入成功显示已入库，不自动离开书架；在主题内发起导入时归入该主题。

书架与成员关系持久化在版本化书库快照；旧版本显式升级并保留原资料，不移动 PDF 或重新生成固定页。领域验证名称与合法 ID，跨书架移动保持单一归属，存储失败不能伪装成功。测试使用原创材料与假网络服务，覆盖迁移、去重、移动、删除保留论文、重启恢复和查询取消隔离。保持真实 API 与用户数据不进入测试。
