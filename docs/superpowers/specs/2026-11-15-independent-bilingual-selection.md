# 中英文独立选文与共享对象

用户已确认实施：中英文各自选择、引用和高亮；跨段中文选文不得混入英文正文，英文亦然。本文取代此前整段译文联动设计；不新增词语或句子对齐模型调用。

选择语言由手势起点的正文决定，反向拖选同样遵循起点；从共享对象开始时使用另一端正文语言，没有正文时仅选对象。图片、SVG 图、表格、独立公式为共享对象；行内公式属于所在语言的句子，不额外收集被跳过正文中的重复公式。图注按正文语言过滤。图片与图表、公式本体按整体引用，保存稳定内容块内的对象位置；文字则保留所属语言及 UTF-16 范围。图片通过跨段拖选或放大窗口内的“引用图片”选择，复制输出对象说明，模型上下文沿用原文块定位，不声称文本模型理解图像。

拖动与引用保留实际字符；点击高亮才排除英文首尾不完整单词。完整单词组成的半句可高亮，中文按实际字符范围高亮。词内连字符与撇号作为词的一部分。新高亮不会联动另一语言；旧批注原来的坐标与关联语义保持，不能静默改写用户历史记录。

只通过文字 CSS Highlight 与对象 outline 呈现，不改变正文布局、不重排论文、不替换完成段落。待译与流式未完成译文不产生持久化选文。新定位字段可选，兼容旧记录；每个选中块均作为问答优先证据。测试覆盖中英双向/反向/跨段过滤、复制、高亮三个单词边界例、共享对象、晚到译文和重开恢复；构建 Mac 后用 Computer Use 检查实际窗口。iPad 构建与真机验收分别报告。
