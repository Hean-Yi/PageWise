# HTML 阅读笔记与页边卡片设计

状态：用户已确认交互方案及卡片空间预算方向；本文记录设计，不代表功能已经实现。适用当前 HTML 连续阅读器。原 PDF 笔记交互不在本轮范围。

## 核心约束

- 同一份笔记可在浮动卡片、页边卡片和右侧笔记列表中呈现。切换侧栏不复制记录，不丢失草稿、光标与编辑位置。
- 中英文笔记分别绑定实际字符范围，跨段不夹入另一语言。图片、表格、独立公式作为共享对象；行内公式沿用现有选文规则。
- 笔记锚点独立于高光记录 ID。局部改色、拆分高光、切换下划线或取消标注不删除笔记、不改变笔记范围。
- 文本浮起、波浪线、连接线及卡片不能改变已发布正文节点、换行和版式，不覆盖原始 PDF。
- 卡片预算指显示空间，不以该预算截断或丢弃笔记正文。超长内容通过卡片内部滚动访问。
- 本地草稿自动保存；只有用户主动触发才写入 Obsidian。

## 入口与标注操作

点击已有高光或下划线，选中所点标注的完整范围，文字轻微上浮，打开笔记卡片。无笔记则进入空白编辑，有笔记则加载原笔记。拖选文字后点击现有菜单的“添加笔记”，将菜单展开为相同的编辑卡片，沿用实际选区，允许部分单词与跨段范围。

未标注文字添加笔记不自动套用黄色高光；用户可主动设置颜色和高亮/下划线。仅笔记的文字通过波浪线表明笔记存在。

编辑卡片顶部保留八色色板和高亮/下划线切换；选中颜色加深。完整已标注范围显示取消标注操作。标注立即应用，选区持续显示；混合范围或局部编辑只影响所选部分。取消高光不取消笔记及波浪线。

预览卡片不常驻完整编辑工具，以正文为主；点击卡片进入编辑时展开工具区。删除笔记是更多菜单中的独立动作，支持撤销，不等同于取消标注。空白的新建卡片关闭后不创建空笔记，也不撤销用户已主动应用的高光。

## 一张卡片的结构

编辑状态从上到下：颜色；高亮/下划线及适用时的取消标注；笔记标题与“编辑/预览”；笔记正文；本地保存状态与“完成”。

沿用应用的暖白背景、细边框、圆角和阴影。预览显示渲染结果，编辑显示 Markdown 源码，切换时保留光标与滚动位置。完成后默认回到渲染结果。输入停顿后更新可复用的预览，避免每个字符都重新构建整篇文档。

## 显示预算与排布

以下为首轮实现与实机验收的默认设计值，单位为逻辑 pt/CSS px，不是截图物理像素。窗口高度变化时动态收紧，不通过缩小文字强行塞入。

| 项目 | 默认预算 |
| --- | --- |
| 页边卡片宽度 | 220–280，优先 240 |
| 浮动编辑卡片宽度 | 320–360，受视口可用宽度约束 |
| 页边未激活状态 | 最多 3 行正文摘要，卡片总高度不超过 112 |
| 激活/编辑卡片高度 | 不超过 min(420, 可用视口高度减 32)，包含工具栏和底栏 |
| 卡片与选区距离 | 10–12 |
| 卡片之间的间隔 | 至少 12 |
| 视口安全边距 | 至少 16 |
| 正文预览字号 | 默认 15，行距约 1.55，跟随应用可访问性字号设置 |
| 标题字号 | 按卡片正文比例分级，最大约 1.35 倍正文 |

预算不足时优先限制正文滚动区高度；工具与完成按钮保持可达。完整展开表示可访问全部渲染内容，取消三行摘要限制，不表示任意长度笔记无限增高。

侧栏展开时显示贴近选区的浮动卡片，优先下方，不足则上方，不遮挡作为锚点的文字。下方和上方均不足时在读者可见区域选择邻近空白位置，以连接关系说明归属；无法满足时提供可滚动的受限卡片，不遮挡当前锚点。

侧栏收起时利用正文两侧空白，按实际宽高预算和已有卡片计算放置。两侧均合适时右侧优先，右侧拥挤则左侧。卡片允许高于或低于锚点，同侧保持正文顺序并纵向避让。侧栏是否存在是呈现偏好，实际空白尺寸是最终依据，不能假定收起右栏后一定有足够空间。

局部笔记过密时，未激活卡片使用摘要收起。Hover 后先使用附近空白展开；空间不足时降低展开高度并内部滚动，必要时当前笔记回退为浮动卡片。不得让卡片相互遮住编辑控件或挤动正文。激活时计算一次合适位置；输入期间不持续重排周围笔记。窗口变化和字号变化才重新计算边界。

侧栏开关后根据同一笔记重新分配位置；已有草稿、光标、焦点和滚动位置保留。非当前视口附近的笔记按需呈现，内容仍保存在本地，右侧列表可定位全部笔记。

## 状态与动画

| 状态 | 文字 | 卡片 | 连接线 |
| --- | --- | --- | --- |
| 未激活 | 原位置；有内容的笔记显示波浪线 | 页边卡片最多 3 行、颜色弱化并轻微虚化；浮动卡片隐藏 | 隐藏 |
| Hover 原文 | 上浮 1–2 | 页边卡片上浮 2–3、恢复清晰并展开；侧栏打开时出现预览浮卡 | 页边模式从原文向卡片延伸 |
| Hover 页边卡片 | 对应文字上浮 1–2 | 上浮 2–3、恢复清晰并展开 | 从卡片向原文反向延伸 |
| 点击编辑 | 保持激活 | 保持展开、固定编辑位置，鼠标移走不收起 | 页边模式保持可见 |
| 完成/点击外部结束编辑 | 回落，笔记波浪线保留 | 页边卡片回落并收起；浮卡关闭 | 淡出 |

Hover 建议停留约 150 ms 后激活；离开文字与卡片共同作用区域约 180 ms 后收起，避免跨越间隙时闪烁。点击无需等待 Hover 延迟。Hover 不抢输入焦点，不覆盖其他正在编辑的笔记；一个时刻仅有一张主动展开的笔记卡片，切换前本地保存现有草稿。

卡片上浮与展开使用同一条约 180 ms 的缓动过程，阴影略加强，避免先瞬间变大再单独漂浮。正文不随卡片展开移动。回落/收起约 160 ms，不做持续晃动。未激活卡片只轻微弱化，摘要仍可辨认；焦点和激活状态完全清晰。减少动态效果时关闭位移与曲线绘制动画，只保留短暂淡入淡出。

虚线采用平滑曲线，从文字选区外缘连接卡片近侧边缘，可有高度差。连接线不穿过笔记正文，不遮住论文字符；跨段选区只画一条主要连接线，其余范围保持选中反馈。连接方向通过一次绘制过程表达，不用持续流动的虚线干扰阅读。源锚点离开视口时隐藏连线，卡片提供返回原文定位。

iPad 没有 Hover 时使用点按激活并展开，再点卡片正文编辑；外接指针沿用 Hover。键盘聚焦具有等价的展开和定位反馈。

## 波浪线与重叠笔记

完成的非空笔记在对应实际字符下方显示细、低振幅、带手绘感的波浪线；与普通下划线错开，不扩大到整个段落或另一语言。对象笔记使用对象边缘提示，不能在图片或公式内部绘制波浪线。

笔记提示与正文标注共享 Hover 命中范围。重叠的多条笔记不自动合并，不层叠多条波浪线；显示轻量数量入口，卡片内选择目标笔记。未重叠且锚点完全相同的添加操作默认打开已有笔记，不无意重复创建。

## Markdown、数学与保存

支持段落、分级标题、列表、任务列表、引用、链接、代码及表格；行内数学使用 `$…$`，独立数学使用 `$$…$$`。公式与正文共享相对字号。过宽的公式、代码与表格局部横向滚动，不把整张卡片撑出预算。

未闭合或有错误的公式保留用户源码，在对应区域提示，不阻止其他内容渲染或保存。预览只渲染经过净化的 Markdown 和数学内容；不执行笔记中的脚本。数学公式使用已有本地编译能力并明确支持范围，不把完整 TeX 文档工程视为可直接运行的输入。

输入草稿本地自动保存，界面显示保存中/已保存；完成、切换目标和退出阅读时立即提交待保存文本。保存失败明确提示并保留内存草稿，不能显示已保存。恢复时返回用户最后的 Markdown 源文；预览可从源文重建，无需额外保存多份笔记正文。

新笔记独立记录笔记 ID、论文与稳定内容版本、语言/对象锚点列表、选区原文、Markdown 源文和创建/修改时间。不只保存屏幕矩形或高光 ID。旧书库通过显式可测试迁移增加笔记集合，不重写旧高光、聊天和原始文件。

右侧笔记页增加阅读笔记汇总，与书签、划线和总结区分。点击汇总条目定位并激活同一笔记。Obsidian 仍只在用户触发保存时输出，保留原有用户区及讨论整理选择。

## 验收要求

- 两个入口打开同一编辑组件；部分单词、多段中文和共享对象的笔记正确定位，不混入另一语言。
- 修改颜色、模式、局部覆盖及取消高光后笔记仍在；删除笔记与取消高光互不替代。
- 侧栏开关、窗口尺寸变化、字号变化及保存重开后笔记不重复，草稿和锚点不丢失。
- 卡片遵守宽高预算；密集笔记、长公式、长代码、长表格、超长笔记可完整访问，不遮挡当前锚点或挤动正文。
- Hover 原文/卡片双向连接和上浮成立；跨越间隙不会闪烁；编辑时鼠标移走不会关闭。
- 源文、公式错误及保存失败不导致内容丢失；空白新笔记不产生无意义记录。
- 未激活卡片收起，激活后展开全部可访问内容；退出激活后回落、收起、隐藏虚线。
- 页面正文节点与几何不因动画和卡片插入改变；减少动态效果和键盘操作可用。
- 先构建 Mac，再通过 Computer Use 检查实际窗口中的各状态、字体、数学、边界位置与侧栏切换；iPad 触摸和 Pencil 能力单独报告，不以模拟器构建冒充真机验收。
