# 双语选文与共享高亮

用户确认：选区背景应贴合文字；跨段选文自动进入聊天栏并显示高亮/解释；引用只使用英文原文，英中共享同一段落的高亮行为。

英文局部选文保持精确 UTF-16 范围；同时跨过译文时排除译文，同一英文段落只收集一次。只在中文中选文时，映射到对应的完整英文段落：当前译文以意译为主，不声称具备词语或句子级对齐。跨段选择按阅读顺序保存多个英文范围，聊天栏用空行连接，不重复拼接中文。

保留浏览器原生拖动、键盘选择和复制能力，但隐藏会铺满块间空白的原生选区背景，用文本节点范围绘制选中色。复制按同一规范化英文选区输出。点击高亮时，每个英文范围独立绑定稳定内容块，并标记关联中文整段；后续译文完成或重开时自动恢复关联高亮。既有 PDF 批注和旧 HTML 高亮保留原有定位语义，不原地迁移。

实现职责：HTML 选择脚本负责收集、绘制和复制；原生桥校验块 ID、顺序、长度及范围；阅读状态保存多块选区；问答将所有选中块作为优先证据。无需模型请求或重新解析论文，不改动已发布 HTML 几何。

验证：真实 WKWebView 检查跨英中/跨段/反向/中文单独选择、英文复制内容、多个稳定锚点、高亮与迟到译文和重启恢复；测试不调用真实 API。构建 Mac/iPad 后，以 Computer Use 在 Mac 实际论文验证拖动选择、聊天栏和操作栏以及高亮显示。
