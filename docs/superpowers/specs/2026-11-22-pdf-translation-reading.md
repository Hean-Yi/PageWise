# 英文 PDF 逐句对照阅读

2026-11-22 设计提案，待确认。用户明确喜欢 NeoRead 能逐句核对中英文的展示方式。以下布局、触发范围及分期为 PaperReader 的设计建议。

## 读者看到什么

原版阅读器增加「逐句对照」。打开后，读者可以从一句中文找到对应的英文原句，也可以沿着英文逐句看中文。默认按窗口宽度选择布局，两种布局都可以手动选择，切换时保留眼前这一句。

**并排对照，适合 Mac 和宽屏 iPad。** 左边保留出版版式的原 PDF，右边按原文段落顺序排流畅的中文，一段里的译句连续排，不给每句加框或编号。指向一句英文，仅淡显该原句和右栏对应译句；指向中文同样联动。一次点击或轻点可固定这对句子，并把屏幕外的对应句带入视野。移动指针只预览可见内容，离开即消退，不抢滚动位置。两栏分界可拖动，初始原页略宽。

**逐句上下排，适合 iPad 竖屏和 Mac 窄窗口。** 在一个连续阅读栏里，英文一句，紧接该句中文，再排下一对。句对内部留小间距，原文自然段之间留更大间距。字号、对比度都要让英文可读，中文用稍高的视觉权重。宽屏上也可以选这种排法。下面是原创示意，展示同一自然段内的两对句子。

> We freeze the encoder during training.<br>
> 我们在训练期间冻结编码器。
>
> This does not reduce inference time.<br>
> 这并不会缩短推理时间。

读者轻点第二句中文时，定位范围是从 “This” 到 “time.” 的整句；第一句保持原样。在上下排模式点「查看原页」会带着这一句的轮廓回到 PDF，便于看图、核查脚注或用 Pencil 书写。返回逐句对照时接着读第二句。

NeoRead 的 PDF 设计提供原文、对照、重排和译文四种视图。在对照视图里，划词可以双向指示对应整句，跨句选择对应多句；重排视图按自然段把译文放在英文下面。这里借鉴其双向找句和切换后保留位置的做法，并为小屏设计逐句上下排。[NeoRead PDF 阅读设计](https://github.com/cynicalight/NeoRead/blob/955ae18f8b0fe8c42fc45f75e1ac79d538d4d2fe/docs/pdf-translation.md#L26-L46)

## 从翻一句到读全文

1. **翻译选区。** 在原版页选英文，点「翻译选区」，就地展开原文和译文。选半句就翻半句，结果标为「选区译文」；选了多个完整句子就按句对应。读者可以从这里进入「逐句对照」。首版遇跨页手动选区，在发送前提示逐页选择，避免只翻第一页却显示整段已完成。
2. **翻译本页。** 打开「逐句对照」先显示本机已有译文。当前页尚未处理时，主操作是「翻译本页」。一个自然段的句对校验完就开放阅读，其余位置显示待译状态。之后翻页只浏览已有结果。
3. **翻译全文。** 在同一入口的菜单中选择「翻译全文」，界面显示总页数、目标语言和已配置的模型服务，点击开始才发送文字。当前页优先，其余按页处理，可以暂停。重开论文可离线读完已保存的部分，也可以继续余下任务。

翻译由 Mac 或 iPad 各自在设备上组织，按请求范围向用户配置的服务发送文字；首次调用前在操作旁说明发送范围。沿用设备 Keychain。导入、查看已有译文及切换布局均无模型调用。直接导入的 PDF 和线上只有 PDF 的论文使用同一入口。线上已有 TeX／同版本 HTML 的连续双语重排继续按既有方式打开。[现有导入与双语阅读范围](../../requirements.md) · [源码重排设计](2026-11-16-online-tex-first.md)

## 两边如何跟随

- **滚动。** 并排模式默认以视口中正在读的源句为基准；读者主动滚动的一侧带动另一侧把对应句保持在可见区域。译文长短和 PDF 的双栏布局会使两边高度不同，定位依据是句子和阅读顺序。程序触发的滚动不会反向驱动另一侧。关闭「跟随原句」后可分别浏览，轻点句子仍可找回对应位置。
- **选择和批注。** 拖选中文的半句时，对侧淡显对应英文整句；跨两句就淡显两句。复制、高亮、写笔记保留实际所选中文字符，英文选区亦然。对应提示保留到选区清除或更换，固定句可再次点选或按 Esc 解除。临时提示与已存高亮使用不同外观。
- **助读与位置。** 并排模式下译文复用现有右侧辅助区域，切到助读或笔记时保存活动句，返回后恢复。上下排时助读可收起，正文只有一个滚动面。Mac 支持键盘逐句前后移动；iPad 的轻点、VoiceOver 的「查看对应句」都可完成定位。触控无需悬停。
- **原页与证据。** 译文显示 PDF 物理页号，句内核对时再出现「查看原页」，跳到该句的实际行框。中文选区问答同时携带选中文字和对应英文，回答引用回到当前论文原页。手写及原版高亮仍绑定稳定原页。明确保存到 Obsidian 时，摘录可带上中英文、页码及来源，讨论整理沿用原流程。

## 译句如何配准

设备先从可用的 PDF 文字层提取带行位置的文本，核对页内阅读顺序，再按自然段和英文句界分割。每个源句记录文档哈希、来源段与句标识、英文快照、页键、字符范围及逐行区域。连字、行末断词的归一化需保留到原始字符的映射。英文缩写、图号、小数和引用号都可能干扰断句，例如 “Fig. 2”、“et al.” 和 “3.14”。不得仅按句点切分。

页译和全文翻译按自然段给模型上下文，请求按给定的源句标识返回对应中文。发布前校验来源覆盖、顺序、去重、数字、单位、引用号和受保护的公式标记；模型只返回译文和来源标识，原页坐标由本地决定。正常句对允许中英语序不同。一句英文需要两句中文表达时，两句中文作为同一个译文单元。确实需要相邻两句合译时，明确标注「两句合译」，点击任一侧会指示整组。覆盖校验不能证明译意准确，真实语言质量须另行评估。

原文顺序可靠、但句间配对校验失败时，可按当前段有限重试；仅当整段来源和译文覆盖可核对时显示「本段对照」。某个双栏区域混栏、文字残缺或公式影响句意时，标出受影响区域及原因，提供原页和手动选译，绝不把两列中位置相近的句子强行配对。页末半句缺少可靠续接时保留原文，明确标出续页；其余已核对句对可照常阅读。

## 论文里的特殊内容

标题、摘要、正文、可提取的图题、表题和实质性脚注参与翻译；术语、否定与限定条件、实验数值和引用编号应忠实保留。独立公式、表格、代码和图片以原页为准。译文中的「图 2」可在位置已核实时跳回原图；只有页级依据就提供「查看原页」。行内变量保持与原文一致；符号损坏会改变句意时，整句提示核对原页。参考文献保留原文。

扫描页显示「本页没有可提取文字」，提供整页原版。全文结果区分已译、部分可译、保留原文和待处理页，并可直接跳到缺失处。读者能看见哪些内容还需要在原页阅读。

## 保存、恢复与实施顺序

完整句对按段提交，新增结果保持当前可见句的位置。暂停、网络失败或 iPad 进入后台时保留已提交的块。重启后以源句集合、原文摘要、目标语言和翻译配置去重。中文批注绑定译文版本、句对和实际字符范围；重译时产生新版本，旧批注可回看旧译句。同一内容在两种布局间共用一份译文和批注。

建议首个可用版本先把**有可靠文字层的本页逐句对照**做完整，包括并排、上下排、双向指句、选区翻译和原页回跳。第二步把相同的句对处理扩展到全文队列、优先页和断点恢复。扫描件 OCR 与 PDF 版式重建需要另行设计。现有需求曾将本地 PDF 限定为原版阅读、选文和批注；确认本提案后再更新已确认需求并实施。

实施验收使用原创样本和假服务。重点核对下列场景。

- 同段三句、含缩写和小数，点击中间一句，两侧只指示该句全部行框。选中其中文字复制，剪贴板只得到实际选区。跨两句拖选则临时指示两句。
- 一页双栏，中间有跨栏图。左栏末句能配回正确英文，图题能回到原图。对次序不可靠、公式缺字或仅有扫描图的部分，缺失原因和原页可达。
- 切换并排与上下排、旋转设备、打开助读、暂停后重开，均能回到同一个句对。重新翻译后打开旧中文笔记，仍能定位到当时的译句和英文；原始 PDF 哈希与既有批注坐标一致。
- 实现后构建 Mac 应用，用 Computer Use 在实际窗口检查，另验 iPad 分屏、触控及 Pencil。真实模型对否定、术语与数字的质量单独授权实测。
