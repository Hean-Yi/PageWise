# 主页书架导航精简

本轮直接落实用户给定的界面结构：一条可横向滚动的书架栏，第一项固定为“未分类论文”，其后是用户自建书架，末尾是图标加号。选中状态通过短下划线、轻微底色与文字颜色表达；取消叠放封面预览、独立未分类横条、返回全部按钮、重复书架标题及常驻拖放说明。大论文封面仍是页面主体，继续阅读保留现有紧凑呈现。

点击末尾加号在栏下展开一行输入，使用确认/取消图标；创建成功选中新书架并滚动到它。改名继续使用同一编辑区；删除书架仍仅解除论文归属。书架项均继续接受论文拖入，未分类项代表移出书架，不改变底层单一归属与保存规则。

页面主标题稳定为集合名称，书架栏负责当前主题上下文。下方仅保留排序；查询时可显示“搜索结果”。未分类下的标题搜索保持全库检索能力。书架切换、新建编辑区使用短动画并尊重减少动态效果。

在当前书架内点击论文加号，通过既有 OnlinePaperSearch.open(shelfID:) 捕获导入目标；已开始的导入固定原目标，避免切换页面后误归类。仍在当前页面展开查找，不增加弹窗或导航层级。Mac 原生拖放候选修复的人工验收仍待用户反馈，本轮不将它标记为已通过。
