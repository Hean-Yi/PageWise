# 主页书架导航精简

主页默认以一行展示书架。「未分类论文」排在首位，自建书架按原顺序紧随其后。窗口变窄或打开侧栏时，读者可左右滑动查看超出可见范围的书架。点击展开按钮后，书架按可用宽度分行显示，封面区随行数下移。点击收起按钮恢复单行和原有选择。选中项用文字颜色、轻微底色和短下划线标记。每个书架均可点击或作为论文拖放目标。

新建书架的加号固定在分类栏最右侧，与首行对齐。单行横滑时只有书架名称和篇数随手势移动，展开后加号仍在原位。点击加号在书架下方展开名称输入，创建成功后选中新书架。改名使用同一编辑区，删除书架仅解除论文归属。

页面主标题稳定为集合名称，书架栏负责当前主题上下文。排序作用于当前列表，查询时可显示“搜索结果”。未分类下的标题搜索保持全库检索能力。书架切换、分类栏展开收起与新建编辑区使用短动画，遵循系统的「减弱动态效果」设置。

在当前书架内点击论文加号，通过既有 OnlinePaperSearch.open(shelfID:) 捕获导入目标；已开始的导入固定原目标，避免切换页面后误归类。仍在当前页面展开查找，不增加弹窗或导航层级。Mac 原生拖放候选修复的人工验收仍待用户反馈，本轮不将它标记为已通过。
