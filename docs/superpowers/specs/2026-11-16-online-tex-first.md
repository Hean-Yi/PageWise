# 线上论文 TeX 优先获取与重排

日期：2026-11-16。状态：用户已要求实现，受限 TeX 优先路径已接入；下文保留最初设计建议，最终实现范围与验证状态见末节。

## 已确认范围

- 本轮先处理应用在线检索、下载的论文，当前来源为 arXiv。
- 线上论文优先使用同版本 TeX 源码包作为重排证据，替代旧设计的 HTML 优先顺序。
- 延续本地整理源码与资源、AI 辅助结构解析和翻译、本地校验及生成双语 HTML 的分工。
- 原始 PDF 保留用于阅读、核对及解析失败回退；已有 PDF 导入继续直接读取 PDF。
- 导入不调用模型；选择 AI 双语重排后才启动解析翻译。Mac 和 iPad 各自独立运行，不执行下载论文中的 TeX 或代码。

## 实现前代码阅读与差距

以下为代码阅读结果，不是运行验收：

- `ArxivClient.download` 只下载 PDF，`structuredContent` 是旧 HTML 接口，尚无源码包下载接口。
- `OnlinePaperSearch` 和 `LibraryAgentImport` 都调用相同 PDF 下载接口，再通过 `importURLs` 保存原始 PDF。
- 新建重排任务通过 `ReflowEvidenceExtractor` 按 PDF 页提取；模型结构计划、公式保护、完整块发布、恢复检查点和旧版式保留已经有实现。
- TeX 文件清单、包含关系、源码范围、静态解析及源码来源选择尚未接入。已有公式渲染能力不等于支持完整 TeX 论文。

## 建议的用户流程

```text
Search -> Select exact version -> Download TeX + PDF -> Library
                                                          |
                                      +-------------------+------------------+
                                      |                                      |
                                      v                                      v
                               Original PDF                         AI bilingual reflow
                                                                             |
                                                                             v
                                                            TeX evidence -> AI -> Validate
                                                                             |
                                                                             v
                                                                  Append bilingual HTML
```

用户仍只执行一次“导入论文”，不用选择文件格式。下载对象是同一论文明确版本的资料集合：TeX 是优先解析来源，PDF 是原版。源码下载失败不应让可用 PDF 无法入库；PDF 下载失败时不得显示“已可阅读原版”，第一阶段建议保留可重试下载状态而不提交完整论文记录。

建议导入阶段下载并保存源码包，但只做格式、大小和身份校验；解包、正文解析与模型调用在选择重排后进行。这样下载完成后无需再次联网获取源码，可明确区分下载等待和解析等待。此下载时机替代旧方案中“选择重排后才下载结构化来源”的建议，尚不是实现结果。

搜索结果必须绑定明确版本号。没有版本号时先从可信元数据解析版本，不请求两次动态 latest 后假定内容同版。两条在线入口共享同一获取用例、取消机制、临时文件清理和重复导入规则。

## 来源选择与回退

```text
Same-version TeX
    |
    +-- supported and complete -> source blocks
    |
    +-- unavailable or incomplete -> same-version HTML
                                         |
                                         +-- verified -> source blocks
                                         |
                                         +-- unavailable or incomplete -> PDF / OCR
```

建议继续利用已有 HTML 适配器作为第二选择，不在可用 TeX 前请求 HTML。源码包可能是 gzip 压缩的单个 TeX 或包含多个文件的 tar 包，不能用文件扩展名判断正文类型。[arXiv 源码包说明](https://info.arxiv.org/help/unpack.html)

第一阶段建议在发布首块前确认来源是否可用。未知宏、缺失包含文件、多个无法唯一识别的主文件或关键资源无法恢复时，明确回退下一来源；不以“成功解析了部分内容”代表整篇完整。网络暂时失败与确认不支持分开记录，取消立即停止，重试遵守有界退避。

局部补充只有在来源位置能够可靠对应、内容所有权明确时才允许；无法对应时不把不同来源的正文拼成一份。完整性检查不只比较字符数量，也检查参与正文的文件、环境、公式、图表和引用的处置记录。

已发布前缀不可被另一来源静默替换。任务恢复固定输入版本、哈希、解析器版本及来源路线；若后续发现无法继续的内容且不能可靠局部回退，暂停并解释原因，使用新的阅读版本重新生成，保留旧内容与批注。

## TeX 与 AI 的分工

设备端识别主文件和包内 `input/include`，建立正文顺序、源码范围、章节、段落、数学对象、图件与引用标签。空行、环境和段落命令决定候选边界，不按 PDF 页或固定字符数截断自然段。预导言中用于正文的宏定义作为受限上下文处理，注释、未引用草稿和无关附件不自动进入论文正文。

第一阶段只支持可静态解释的语法与有界纯文本宏展开；未知命令显式保留为未解决项，不直接删命令再假定剩余文字完整。复杂条件、动态文件名、TikZ、特殊表格和宏包效果不交给模型猜测执行结果。数学源码也需要对应宏上下文，无法可靠渲染时回退。

AI 接收带稳定来源 ID 的证据块及必要上下文，整理结构和翻译正文。公式、图片、表格和引用目标由本地登记并保护；模型只引用对象 ID，不生成资源路径、任意 HTML 或 PDF 页码。正文、标题及独立图注翻译；图内文字、表格、公式、代码和参考文献保留原文，作者与机构沿用现有非正文处置。

本地校验来源覆盖、顺序、对象引用、公式标记和译文完整性，只有通过校验的完整块才发布。有效源码减少结构猜测，但不能据此承诺模型更快、成功率更高或所有论文都能无损转换；需样本测量。

## 存储、定位与恢复

建议论文来源记录保存明确 arXiv ID/版本、获取地址、内容哈希、格式及可用状态。源码证据保存包哈希、文件相对路径和字符范围；解析块拥有稳定 ID，模型合并后保留全部来源跨度。

源码位置不能充当 PDF 页码。没有可靠 PDF 对齐时，引用定位到阅读版式内的原文块；PDF 页码保持未知。重新生成保留旧版式和批注，旧 PDF 任务恢复时不自动切换到源码。

下载与解包结果在独立暂存目录准备，校验后原子提交文件，再提交数据库引用。取消、磁盘失败和重复导入清理未提交制品；已成功入库不因迟到的取消被标成失败。新增字段必须兼容旧快照，有迁移时显式编号并测试。

建议任务未完成时保留源码包、清单及必要资源，保证重启可恢复；完成后仅清理无依赖的临时副本。长期保留范围需要结合重新生成需求决定，不能清理唯一的可恢复证据后又宣称能离线重建。

## 设备端处理边界

解包使用 Mac/iPad 共同支持的库或系统接口，不依赖 shell、Python、TeX 安装或自建服务。拒绝绝对路径、目录穿越、符号/硬链接、重复覆盖路径及包含环，包内文件不能访问包外路径。限制压缩体积、解压总量、文件数、包含深度和宏展开预算；具体阈值沿用旧设计候选值并通过测试调整。

下载资料只作为内容，不具备工具调用或修改提示指令的权限；不执行下载脚本或样式包。密钥继续仅从设备 Keychain 读取。

## 实现与验收顺序建议

1. 统一线上获取返回值与来源清单，接入同版本源码下载、PDF 保留、取消与失败降级；覆盖两条在线入口。
2. 增加受限解包和静态解析，将源码证据接入已有联合重排与检查点；保持旧 PDF 任务可恢复。
3. 用原创 fixture 覆盖单文件、多文件包含、宏、公式、图注、引用、缺资源和异常压缩包；验证回退无丢失、无重复、引用不伪造页码。
4. 验证同版本约束、来源优先级、导入不调用模型、重复下载清理、暂停重启和旧批注保留；构建 Mac 与 iPad。
5. 另行执行实际应用窗口验收及经授权的真实论文/模型验证，记录样本、失败边界与首段耗时。自动化通过不代表视觉或真实模型质量已经通过。

## 本轮实现范围

在线查找和书库 Agent 均调用 `downloadPublication`：无版本候选先解析明确版本，先请求同版本源码，再下载 PDF。源码格式/来源失败记录提示并保留 PDF 路径；取消立即停止。导入保存源码哈希和相对路径，不解包、不调用模型。重复导入可为没有源码的同版本论文补充源码，不覆盖已有任务或原 PDF。

`TeXArchive` 在内存中读取 gzip、单文件 TeX、普通 tar/ustar；拒绝链接、路径越界、重复路径、校验和错误及超限。PAX/GNU 特殊归档记录暂不支持。`TeXDocument` 确定唯一主文件并展开包内包含，受限宏仅允许预导言顶层定义；正文局部定义、重定义及动态条件不猜测。`TeXMarkup` 支持章节/自然段、受支持数学、图件/图注、简单 l/c/r 表格和 .bbl/thebibliography，正文未知命令明确回退。原始代码环境不展开包含和宏。引用链接显示源码标签或文献键，不伪造原论文编号。

本地公式仍使用既有 KaTeX，图件通过只读取包内数据的传输适配器复用现有解码器；该适配器不会访问网络。表格与参考文献保留原文。源码当前先完整解析再启动渐进模型生成，因此没有宣称首段比 PDF 更快。

`OnlineSourceStore` 校验保存的原 PDF 与源码哈希。TeX 完整转换后才提交来源块；失败时尝试同版本 HTML，再进入 PDF 按页提取。检查点固定 tex/html/pdf 路线，旧任务缺省保持原 PDF 行为。块 ID 从包哈希、主文件、解析器版本及块序号派生；来源跨度保留 TeX 锚点，不能可靠对应的 PDF 页码为 -1。尚未保存逐文件逐字符的精细源码范围，该能力仍是后续设计方向。

新增领域字段均为可选，旧 v8 快照缺省 nil，旧任务、原文件和批注不迁移或改写。源码包按内容哈希原子落盘并保留，未提交导入由原有暂存清理负责；完成的 HTML 不依赖源码包解码才能打开。旧阅读版本在重新生成时保留。

新增 `ReaderSmoke --tex-preview <fresh-directory>` 可创建原创离线验收书库，译文明确标记为排版测试内容，不代表真实模型质量。实际检查结果见 [MVP 状态](../../mvp-status.md)。
