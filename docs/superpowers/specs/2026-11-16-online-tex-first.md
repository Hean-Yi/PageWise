## 最短路径

```text
Online candidate -> versioned PDF + TeX archive
                           |
                    choose bilingual reading
                           |
                    static TeX parse
                           |
                    same-version HTML (if TeX fails)
                           |
                    validated blocks -> bilingual HTML

No complete source -> original PDF reader
```

线上搜索与书库 Agent 共用下载和导入接口。原 PDF 按哈希保存，TeX 包保存版本、路径与校验哈希。导入时准备论文摘要，完整源码解析和模型翻译在打开双语重排时启动。线上补齐来源的本地 PDF 沿用论文 ID 和已有阅读内容，之后从「双语重排」打开源码版。本地导入且尚无线上来源的论文从同一入口打开 PDF 段落或逐句对照。详见 [PDF 阅读设计](2026-11-22-pdf-translation-reading.md)。

选择重排时静态解析包内源文件与资源，支持的包含、宏、公式和表格转换为统一语义块。包外路径、未知动态结构、资源缺失、图件失败均拒绝作为完整 TeX 来源。之后尝试同版本 HTML；仍不可用时显示原因并提供原版，不从 PDF 补文或裁图。

模型沿已知来源顺序整理段落与翻译，图片/公式由本地保存。校验完整覆盖、唯一归属、顺序、对象和公式后发布完整块。中断仅保留已提交前缀；新的来源/模型设置不改写旧阅读版本。源码锚点包含包摘要、主文件与展开块序号，PDF 页码未核验时未知。
