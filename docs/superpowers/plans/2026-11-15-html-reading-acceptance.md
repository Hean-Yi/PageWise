# HTML 阅读验收与下一步

先完成用户实际书库的验收，不用示例成功代替真实论文成功。

1. 构建 Mac 应用，用 Computer Use 启动新构建；对旧导入执行重新解析，检查真实模型的英中段落、行内与独立公式、SVG、原页补全、连续滚动。
2. 验证退出重开读取已保存 HTML，翻译从断点继续；检查原 PDF 不变、一套 HTML 和去重资源，无重复论文记录。真实论文与日志仅保留本地，不入 Git。
3. 扩充独立图片裁剪评测样本，人工标注图框和失败原因，按既有定义测量 99% 目标；未达标前不宣称成功率。重点处理包含 foreignObject 的 SVG 与局部转换错误。
4. 在最终样式上重新测量首屏与滚动，区分 WebKit 冷启动、预热和低电量模式；继续优化首次 100 ms 目标，补充 iPad 真机运行与触控滚动。
5. HTML 内嵌手写单独设计；保留现有 PDF 批注，暂不迁移几何坐标。

当前流程仍需点击翻译才发布双语 HTML；导入成功不等于完成重排。是否增加无需模型的完整英文连续阅读及其向双语版的过渡，需单独明确锚点与版本行为，不能通过重复缓存或静默替换已有版式解决。
