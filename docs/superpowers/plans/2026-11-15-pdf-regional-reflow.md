# PDF 局部重排与覆盖核对实施计划

目标：修复过度整页回退及 Reference 重复，以用户已导入的全部样例核对实际结果，不将加载成功或整页图片当作文字重排成功。

架构：PDFKit 提取文字与几何，按阅读顺序生成标题/段落；设备端像素区域分析仅保留不适合重排的图表/公式局部。HTML 覆盖不足先核对规范化文本，补入缺失内容前检查重叠，禁止直接叠加已覆盖整页。已有阅读制品通过显式操作发布新文件，批注依赖继续受保护。

技术：Swift 6、PDFKit/CoreGraphics、现有 HTMLReadingStore；无 OCR、无新服务、无模型调用。

- [ ] PDF 局部恢复：在 Infrastructure/PDF/Import 新增区域适配器；接入 PDFProcessor。按行提取、合并同一行碎片、定位图形/公式区域，正文重排，复杂区域原样裁剪。字符覆盖必须完整且唯一；失败明确保留原页。
- [ ] 覆盖检查：在 PDFImporter 的 HTML 补全过程中识别排版连字符/空格差异与已存在参考文献；缺失页优先文字恢复，重叠内容不重复插入。用本地原创 fixture 检查已有参考文献、局部缺失和真实缺页。
- [ ] 已入库更新：修正 ReparseActions 对未翻译 HTML 的重建限制；保留原始 PDF/论文身份/已匹配译文/已有标注。验证重启和清理，不直接编辑用户数据库。
- [ ] 样例审计：增加 ReaderSmoke 的只读审计入口，对显式指定的本地书库逐篇统计页数、文字恢复、局部保留、整页回退、内容覆盖；报告写入忽略目录，不提交真实论文素材。
- [ ] 运行相关回归和完整检查，构建 Mac/iPad；Computer Use 启动最终 Mac 构建检查正文、参考文献、公式/图表。通过应用入口更新可安全重排的样例并复核；已有批注依赖的版式不得覆盖。
- [ ] 文档记录实测结果及边界，相关检查后独立本地提交。100% 为用户验收要求，未达到的部分逐项如实报告，不以阈值或图片占位冒充通过。
