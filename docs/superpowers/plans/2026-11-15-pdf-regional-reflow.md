# PDF 局部重排与覆盖核对实施计划

目标：修复过度整页回退及 Reference 重复，以用户已导入的全部样例核对实际结果，不将加载成功或整页图片当作文字重排成功。

架构：PDFKit 提取文字与几何，按阅读顺序生成标题/段落；设备端像素区域分析仅保留不适合重排的图表/公式局部。HTML 覆盖不足先核对规范化文本，补入缺失内容前检查重叠，禁止直接叠加已覆盖整页。已有阅读制品通过显式操作发布新文件，批注依赖继续受保护。

技术：Swift 6、PDFKit/CoreGraphics、现有 HTMLReadingStore、同版本公开 arXiv HTML；无新服务、无模型调用。用户允许 OCR/AI 辅助；已评估本地 Vision OCR，但尚未接入产品，不能描述为已实现。
