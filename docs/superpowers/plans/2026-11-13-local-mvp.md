# Local MVP Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for isolated PDF work and independent review. Execute remaining tightly coupled integration in this session; user has authorized implementation.

**Goal:** 可安装运行的 Mac / iPad 本地 MVP，Mac 支持文件拖拽，普通 PDF 也进入解析与重排流程。

**Architecture:** SwiftUI 应用 + 共享 Swift Package。PDF 服务输出语义块和不可变页面；SQLite 保存完整本地记录，文件保存原文与页面。GLM 和 Obsidian 均通过显式服务接口调用。

**Tech Stack:** Swift 6、SwiftUI、PDFKit、Core Text、PencilKit、SQLite、URLSession、Keychain。MVP 先实现设计中的原生固定页排版分支，减少 WebKit 导出与选文映射的不确定性；复杂 PDF 必须显示降级原因。后续保留 WebKit/HTML 路线。

## 版本边界

本次为可用本地 MVP，不声称生产级同步、任意复杂 PDF 无损重排、手写 OCR 或真实 GLM 账户验证。CloudKit 留待会员。对于复杂图表/公式，以保留原始 PDF 和可追溯原文入口保障阅读；可重排的文字 PDF 必须真正生成新页面，而不是只换个 PDF 查看器。

## 实际执行调整

采用系统 SQLite 快照存储代替 GRDB；检索采用本地分词排序而非 FTS5。当前阶段未实现资料包导入/导出、HTML/复杂公式重排或 CloudKit；详见 [MVP 状态](../../mvp-status.md)。26 项测试与两端构建通过，真实外部 API 和硬件仍待验证。
