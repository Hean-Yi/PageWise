# 已确认需求

本文件归并截至 2026-11-24 的确认内容。实现与实测结果以 [MVP 状态](mvp-status.md) 为准。

## 平台与本地阶段

Mac 为主要设备，最低 macOS 15；iPad 可独立下载、解析、翻译、阅读和问答，不依赖常驻 Mac、Python 服务或自建服务器。第一版面向个人和少量朋友，各自管理资料与 API。先完成本地 MVP，不自行部署或上传资料。

Mac 提供可分享给同学的 DMG 试用包。空书库首次打开时，引导依次高亮实际书库、阅读器与侧栏中的操作入口。读者可以直接操作控件，拖选原文后跟随高亮找到写笔记的铅笔，也可以跳过或重看引导。

应用随包提供原创教学 PDF。快速上手的试读固定打开这份示例，空书库和已有论文的书库都可直接进入，重看时复用同一份示例及其批注。原文阅读、划线和写笔记支持离线体验。每位读者使用自己的书库和模型凭据，翻译和助读由读者自行发起。

iCloud 自动同步、App Store 与正式公证分发是后续目标，待开发者会员、签名、真机与多账户验证可用后接入。

## 论文获取与源码重排

线上按完整或模糊标题检索，来源和下载地址必须可验证；版本或候选不明确时展示作者、年份与来源供选择。主要领域为计算机 / AI。

书架在线查找和书库助理都应区分索引暂时无法连接、部分索引完成和全部查询成功但没有命中。默认并行查 arXiv、Crossref 与 DBLP，可以限定来源。对当前论文找相关工作时，使用 Semantic Scholar 的论文推荐。服务限流时遵守等待时间，读者可以取消等待。书库助理执行多步检索时，模型从第一次请求起就应知道本次提问可用的工具轮数和调用次数，能按剩余额度安排检索、筛选和回答。

书库助理按读者想找的资料选择来源。下载论文或找新文献时直接在线查找。按 DOI 合并重复书目，明确关联的预印本和出版版本保留各自操作。可核验开放全文的推荐卡提供下载按钮。读者点击后自动下载并导入，连续点选多篇时按顺序处理，在各自卡片上查看进度、取消、重试或打开已入库论文。查已收藏的论文或以前写的笔记时使用相应的本地检索。读者要求先核对书库再补下载时，仅对书库缺少的论文发起在线检索。

缺少全文直链时，结果卡支持按可核对的书目编号一键查找开放 PDF 并下载入库。取得文件失败或缺少可查询的编号时，提供出版页与手动选取 PDF 的后备操作。读者在浏览器取得文件后，可回到同一张书架或助理卡片选择 PDF 入库，再从卡片打开阅读。书架导入沿用发起检索时的目标书架。手动选择记录文件与当前书目的关联，首次导入使用本地 PDF 重排。与已有文件完全相同的 PDF 复用原馆藏，保留笔记、批注和阅读版本。

书架提供按住空格的封面预览。指针悬停在论文上时，封面放大，简介随后出现。默认显示原文摘要，有完整本地译文时优先使用中文。精读论文在摘要前展示有依据的一句话概括。松开空格返回原书位。预览本身不启动翻译或精读。导入或下载时准备摘要，按原文件与识别版本保存。旧书库后台补齐，重新预览、重启和重复导入复用已完成的结果。没有显式摘要标题的论文可依据首页排版和章节边界定位。文件暂时不可读时允许重试。

阅读器主入口统一为「原版」和「双语重排」。应用根据导入来源选择重排方式，用户只需选一次阅读模式。书库和阅读器之间的往返应有方向明确的动效。返回书库时，阅读模式控件和论文目录随阅读器一同退出，快速连续切换仍能操作当前页面。点目录标题时正文沿翻阅方向短距离滑入，连续选择以最后一个章节为准。启用系统「减弱动态效果」时避免页面位移。

从在线查找或书库 Agent 下载的论文使用源码重排。导入时保存原始 PDF 并优先获取同版本 TeX 包。用户选择「双语重排」才开始解析与翻译。如果只下载到了 PDF，或 TeX 解析不完整，应用尝试同版本 HTML。两种源码都不可用时说明原因，提供原版 PDF 阅读。

通过 Finder 或系统文件选择器导入的本地 PDF 采用 PDF 文字层和原页图表重排。导入后可直接读原版、选择和批注，导入本身不调用模型。线上再次获取相同 PDF 时按哈希补齐来源，之后统一入口改走源码。已发布的历史版及用户记录继续可读，旧固定页转换任务停止续跑。

源码只作静态解析，不执行包中 TeX、脚本或代码。不凭字符数量、程序无报错或加载成功宣称完整转换。公式、图片、表格、图注、引用和原文顺序须保持；不可靠时不发布残缺内容。

## 本地导入 PDF 的逐句对照

用户确认英文 PDF 逐句对照的设计。带可靠文字层的 PDF 可由用户主动发起英译简中，宽屏对照原页和译文，窄屏逐句上下排列，两种布局都能双向核对原句。单页选区和本页翻译保留独立入口。无法可靠配对的内容标出范围和原因。完整交互、定位与验收条件见[逐句对照设计](superpowers/specs/2026-11-22-pdf-translation-reading.md)。

用户确认增加本地 PDF 的「段落重排」。按原文顺序展示英文自然段及其中文。上下滑动即可读过原页边界，原页码随阅读位置更新，目录和页码支持直接跳转。段内仍能按句核对、定位原页和复用已保存的译句；尚无译文时可以先读英文。进入段落重排即在后台翻译，当前页优先，随后自动处理完整篇论文。翻到新页时优先照顾正在阅读的页，已完成的译句可直接复用，读者可暂停和继续。图表、公式等内容保留原页定位，读者可以随时核查。

用户要求尽可能在连续阅读中读全原文，并能提取规则表格。表头、行列和数值有可靠依据时，直接展示可以选字、复制的表格，保留数值精度、上下标和有意义的强调。复杂表格与图片在相应正文位置展示出版原貌。难以配对的公式、文字或整页保留原版内容，优先在阅读位置就能看到。读者可自选返回原 PDF 核对。图表可在译文完成前阅读。题注和单元格识别须面向不同论文的版式，以原页文字、空间关系和绘制内容核查。跨论文检验同时检查错裁、错列和原有可读内容是否保留。

## 源码双语发布与稳定定位

英文原段在前，简体中文译文在后，按完整自然段处理。正文、标题、摘要、图注和实质性脚注翻译；作者、机构、通讯元信息不进入正文翻译，参考文献、代码和表格保留原文。行内公式保持原对象，图片中文字不翻译。

模型返回计划与流式译文，本地验证完整来源覆盖、去重、顺序和公式。先展示首批可读内容，其余继续生成；增量可预览，完整块才保存。暂停、取消、重启或更换模型不能覆盖已完成前缀，网络/鉴权错误明确提示，自动恢复有上限。

最终阅读格式为本地连续 HTML，不生成纸张分页。已发布内容与锚点不可改写；新内容追加。重新生成保留旧版本和用户记录，不迁移或重新解释旧批注。原始 PDF 永不覆盖。没有核验的 PDF 页码保持未知，源码块与版本可以独立定位。

Mac 失去焦点不取消任务；iPad 真正进入后台允许暂停。首屏 100 ms、阅读 16 ms 是性能目标，须报告设备、冷暖启动与测量边界，不当作已实现事实。重排请求优先降低思考等待，但请求参数不能证明服务实际零思考。

## 批注、问答与记忆

原版 PDF 与历史固定页继续支持高亮和 iPad Pencil 自由笔迹，笔迹绑定稳定页与版式；HTML 手写另行设计。HTML 按稳定内容块与文本范围定位，不强行迁移 PDF 几何批注。

翻译、论文助读和书库助理共用设置中当前选定的服务、模型和对应凭据。设置提供主流国内外服务预设和自定义兼容接口，带入官方地址与可编辑的建议模型。更换服务后，密钥只可用于对应的请求地址。当前论文是划线问答的主要证据，书库和授权 Obsidian 目录为补充；论文事实、外部资料与推断分开，引用可以定位。不能用其他论文替代缺失的当前论文证据。

读者明确委托助理记笔记时，以当前论文的讨论和可核对引文整理观点，一次保存原文标画和本地阅读笔记。源码版定位到稳定版本、语言与字符范围，PDF 定位到原页文字与行框。同一条笔记可关联文中多处证据。读者点名要标画的原句时，标画范围以该引文为准。读者可从回答或笔记侧栏打开、编辑和删除，已有手工标记和笔记中的修改须保留。

读者可在助读侧栏或通过 Agent 发起 AI 精读。用五色本地批注区分核心论点、概念、实证、让步与反驳、方法，串联问题到结论，并独立评估实验数据的解释范围。段落批注围绕具体原句解释方法、对照、公式或论证缺口。文末总结以中文阅读笔记独立成页，沿用正文的阅读宽度和排版，可从目录末尾打开。内容应围绕论文提出具体问题，讲清机制，核查关键比较，区分作者报告、读者解读与待验证的猜想。两者都能回查引文。手动和 Agent 笔记可以引用其他本地论文中已保存的阅读笔记。检索以笔记正文为来源，笔记修改和删除应反映在检索和引用预览中。当前论文的标画和论证依据继续定位到原文。图表的可读范围、论文覆盖情况和引文规则见[精读设计](superpowers/specs/2026-11-23-ai-close-reading.md)。

书库侧栏的「阅读笔记」按论文汇集各次 AI 精读保存的文末笔记。每篇以论文标题和最新笔记正文摘录为主，相邻论文之间用一条物理像素宽的细线分隔。打开原文和整理到 Obsidian 是各篇独立的操作。展开历史可按精读时间和当次关注点找到旧笔记，展开段落批注可回到对应原文位置。

点笔记打开对应的文末页。单击正文可在原处编辑，修改自动保存。拖选文字可复制，点击引用可核对出处。列表反映笔记后续的编辑和删除。已保存且缺少报告关联的文末笔记按创建时间收录一次。退出论文时回到先前的笔记列表或日历，保留已展开的历史和所选日期。

长期记忆记录研究兴趣、知识背景、进展和待解决问题，保留来源并标注推测。用户从「设置 → 研究记忆」编辑或删除条目，有来源论文时可以打开核对。自动提取不得覆盖修正或复活已删除记录。聊天、批注、笔记和阅读事件分别保存。

## Obsidian 与阅读日历

应用读取用户通过系统选择器授权的目录。每篇论文对应 Markdown 笔记，由用户点「整理到 Obsidian」后写入。精读时完成的 AI 综合笔记与各条批注取当前编辑版本，保留历史、出处和覆盖说明；阅读笔记库可以打开和修改它们。读者明确选择包含讨论时单独询问。保留用户内容，检测外部修改和重复追加。讨论整理保留结论与未解决问题，不默认粘贴聊天原文。

阅读日历按本地日期归集前台阅读活动。「当日阅读」中每篇论文只列一次，显示当日累计时长。跨午夜的记录在两天分别计时，同篇重叠时段只计一次。全日总时长同样扣除不同论文之间的重叠。读者可补记、展开单篇明细并删除有误的记录。后台与长时间无操作时保守计时。

## 设计默认值与范围外

iPadOS 18 暂定最低版本；当前主要支持英文到简体中文，密钥每台设备单独保存在 Keychain，不进入普通数据同步。已下载资料离线可读，翻译和问答需要联网。不承诺所有兼容接口一致、任意论文无损转换、全文离线模型、自动识别所有图像或手写。

iPhone、多人实时协作、公开 App Store 上架、Windows / Android、全天候后台任务不在当前范围。

## 2026-11-14 界面补充

用户要求整个 App 以视觉引导操作，突出主任务并弱化次要信息；减少解释性文字、重复口号与技术实现细节。通过 Computer Use 检查真实窗口的视觉与操作。

用户指定参考 Claude 网站的设计语言。书库、阅读工具和设置使用暖纸色背景、深墨色文字、衬线标题和克制的陶土色强调，保留 Apple 平台上的键盘、菜单和系统对话框交互。

书库采用 Apple Books 式大封面，直接呈现论文标题，保留紧凑的继续阅读入口。封面悬停抬升，右上角常驻圆环显示阅读进度，收藏和更多操作仅悬停或聚焦时出现；触摸设备提供长按菜单。添加格默认只有虚线与加号，悬停后动画显示两行“拖拽 PDF 至此 / 或点击在线查找”。移除侧栏“正在阅读”入口，保留“继续阅读”；已读集合不显示添加格，左下保留 PDF 导入，所有集合支持拖放。

进度达到 100% 自动归入已读；全部论文始终把未读完的论文放在已读论文前面，每组内部保留所选排序，侧栏计数使用同一判断。末页已读状态保存后，回看前文不撤销，用户仍可主动标记未读。

右上角使用一个开关控制当前窗口的右侧栏。在书库显示书库助理，阅读时可在论文助读、笔记和书库助理之间切换。窄窗口内仍以右侧栏呈现。Agent 可查本地知识点和在线论文、准备导入、定位论文及具体页；检索、阅读和筛选步骤按时间排列，答完后收起，可展开查看候选与数量。服务公开返回的思考文本或工作进展在本轮回答后仍可回看。最终推荐、引用和导航操作以独立圆角卡呈现，按助理选定的顺序显示，可点开来源或带着这项结果继续追问。遇到需要读者决定的范围，在同一个醒目的提问框内呈现问题、可选项、自定义回答和发送操作。书库与论文助读回答复用笔记的 Markdown 与公式渲染。在线论文来源与导入操作各有入口。回答中实际使用的引用可从编号或来源卡定位，其余检索资料默认收起。当前论文划线问答继续以该论文为主要证据。阅读目录只展示章、节两级，可以逐章或一次收起、展开。PDF 优先使用内嵌目录，再从正文识别章节标题；无法识别时使用页码导航。源码双语阅读按已发布的章节导航。不能把生成的链接或工具意图当作已执行结果。

## 主题书架与连续查找体验

每篇论文只属于一个主题书架。拖拽可移动归属，书架直接显示在全部论文页面。移出或删除书架后，架内论文回到未分类。书库助理可以查看书架及成员、建立或改名书架、批量移动论文。本地新增由用户选择 PDF，在线新增复用下载并导入卡。删除论文时，从封面、阅读器和助理结果卡都会打开带论文名的系统窗口，提供取消及永久删除。确认后清除书库中的文件副本、批注、笔记、对话及阅读记录。重新导入相同 PDF 会建立全新记录。在线查找在当前窗口内容区展开，通过布局过渡保留书架上下文。

从任意主题书架、收藏或已读集合搜索时，按标题检索整个本地书库。候选列出论文标题和所属书架。选中候选后切换到对应书架并定位封面，未归类的论文定位到「未分类论文」。

主页书架栏默认单行显示，分类放不下时可左右滑动。点击展开按钮后，全部分类按可用宽度分行排列，再次点击可收回单行。「未分类论文」居首，自建书架按原顺序排列。新建书架的加号固定在分类栏最右侧，滑动分类或切换展开状态时都可直接点击。选中状态用视觉表达。在书架内点击添加论文，导入到对应书架。

切换分类时，书架栏保持原位，选中标记跟随选择，封面按切换方向显现。用户可以在过渡中继续选择或按住空格预览当前书架中的论文。开启「减少动态效果」时直接显示目标内容。

书架与书库分类（含已读、收藏）在顶部共享「继续阅读」入口，打开全库最近读过的那篇论文。卡片随页面向上滚出视野，回到顶部可再次使用。首次阅读后才显示。

封面拖动参考 Apple Books：完整书封拿起并跟随鼠标，原位置淡化，邻近封面让位，松手落位、取消恢复。支持手动整理并保存自定义顺序，继续遵守全部论文未完成优先；跨书架的有效放置目标有清晰视觉反馈。


## 2026-11-15 中英文独立引用

## 2026-11-15 阅读笔记卡片（本地 HTML MVP 已实现）

点击已有高光/下划线或拖选后添加笔记，使用统一的 Markdown/LaTeX 笔记卡片，并保留标注颜色和模式编辑。侧栏展开时使用选区附近的浮卡，收起时优先在右侧空白分配页边卡片，右侧不足则左侧；空间不足允许回退浮卡。两种显示共用同一笔记和草稿。笔记独立于高光记录，取消高光不删除笔记，未标注文字添加笔记不自动增加高光。

每张卡片有显示空间上限：未激活可收起为摘要，Hover 时上浮、恢复清晰并展开；超出预算的正文内部滚动，不截断内容。目录展开或收起时，跨行高亮和笔记卡之间可沿水平、纵向或斜向移动；到达卡片后能继续阅读，同一次悬停保持位置稳定。正文与卡片可双向 Hover 激活，通过平滑虚线连接；编辑结束及未激活时隐藏连线。非空笔记的文字以区别于普通下划线的手绘感波浪线提示。默认预算、状态、动画、保存及验收边界见[阅读笔记设计](superpowers/specs/2026-11-15-inline-reading-notes.md)。

实现包含独立语言/对象锚点、Markdown/LaTeX 本地预览、草稿自动保存、删除撤销与显式 Obsidian 导出。Mac 构建后的实际窗口验收及未覆盖边界见 [MVP 状态](mvp-status.md)；iPad 构建不等同于触摸真机验收。2026-11-23 增加了原 PDF 选文笔记和助理标画，沿用阅读笔记编辑器。

用户追加：Markdown/LaTeX 必须在输入时实时编译显示；上下滚动不应让笔记卡片卡顿或反复晃动。最新确认要求为在同一编辑区内实时呈现 Markdown/LaTeX，不另设预览窗格；页边卡片跟随原生文档滚动，编辑卡片保持位置，滚动期间不重新分配布局或重建动画节点。

用户追加：收起卡片保留五行中文摘要空间，展开和收起连续过渡；Hover 命中即响应，离开即回落，跨越文字与卡片间的有效通道时不闪烁。虚线增加方向和端点引导，波浪线采用平滑但不规则的手写形态。

中文标注点击修复：点击命中按实际文字边界，Hover 可适度扩展；旧双语联动高光按点击的语言进入笔记。上浮层必须保持跨行中文的实际字形位置，忽略 HTML 折叠空白，不产生重复字符。

点击笔记的弹出效果：虚线引导到卡片连接点，卡片从连接处扩展并轻微弹性回落，呈现果冻感；不移动正文、不反复晃动。快速切换或关闭需取消旧动效，减少动态效果模式禁用弹性缩放。

用户确认标记整体悬浮：文字、高光底色、下划线和笔记波浪线同步轻浮，原位置不留下色块或双影。单行约 2 pt、多行约 1 pt，不缩放文字；只转移选中范围，混合颜色和范围外原标记保留。图片、表格和独立公式保持原位反馈。

用户确认笔记虚线允许穿过论文文字，显示在文字和上浮标记上方，直接平滑连接页边卡片靠近正文一侧的垂直中点，让不同高度的两端自然弯曲，取消避让文字的绕行；不拦截正文交互，卡片内容仍位于连接线上方。
