# 产品需求基线

本文按功能域归并所有已确认的产品需求与不变量；实际实现进度与实测结果以 [验证记录](mvp-status.md) 为准。

---

## 1. 平台定位与分发

- **双端本地独立**：Mac 为主力设备（最低 macOS 15），iPad（暂定最低 iPadOS 18）可独立完成下载、解析、翻译、阅读与问答，不依赖常驻 Mac、Python 服务或自建服务器。
- **个人与小范围试用**：面向个人及少量朋友本地使用，各自管理书库与模型 API 密钥；密钥仅保存在本机 Keychain，不写入普通同步数据或导出文件。
- **分发与内置示例**：Mac 提供可分享的通用 DMG 试用包；随包内置原创两页英文教学 PDF（*When the Average Misleads*），空书库和已有书库均可离线体验原版阅读、划线与写笔记，重看引导时复用同一份示例及其批注。
- **首次引导**：空书库首次打开时启动精简引导，依次高亮书库、阅读器与侧栏的真实入口，展示如何记录笔记与笔记悬停状态；读者可直接操作控件（拖选原文后跟随高亮写笔记入口），并可随时跳过或重看。

## 2. 论文获取与书库管理

### 多源检索与导入
- **并行检索**：书架在线查找与书库助理共用多源检索，默认并行查 arXiv、Crossref 与 DBLP（支持限定单一来源）；对当前论文推荐相关工作使用 Semantic Scholar。
- **状态区分与限流**：明确区分连接失败、部分索引完成与全部成功但零命中；遵守服务限流等待时间且允许取消。
- **合并与下载**：按 DOI 合并重复书目，保留预印本与出版版本切换。开放全文直链或按 DOI 查得的开放 PDF 支持一键下载入库，连续点击按顺序排队，每张卡片展示进度、取消、重试与打开；无公开 PDF 时提供出版页与手动选取本地 PDF 的后备入口。
- **去重与同名规则**：
  - 完全相同哈希的 PDF 复用原记录，保留笔记、批注与历史版本（若本次附带线上来源则按哈希补齐）。
  - 不同 PDF 与全库已有标题同名（统一大小写、全半角与连续空白，保留有效标点）时提示原书架并跳过，批量导入继续处理后续文件。
- **永久删除**：封面菜单、阅读器顶栏纸篓与助理结果卡均弹出带论文名的系统确认框；确认后清除应用内文件副本、批注、笔记、对话与阅读记录，重新导入视为新记录。

### 书架组织、预览与拖拽
- **主题书架**：每篇论文最多归属一个书架，删架后论文回到「未分类论文」。主页书架栏默认单行可横滑，可展开为多行，新建书架的加号固定在最右侧。
- **排序与已读分组**：阅读进度达 100% 自动归入已读（回看不撤销，支持手动改未读）；「全部论文」始终将未读完论文排在已读之前，各组内遵循所选排序，侧栏计数一致。
- **全库混合检索**：在任意书架、收藏或已读视图中均可实时搜索全库标题、正文段落与阅读笔记，标题命中切换至所在书架并标出封面，正文与笔记命中直接跳转对应原页或笔记；「阅读笔记」与「研究记忆」页面同样支持本地词项 + 语义检索与分类筛选。
- **封面与拖拽**：采用 Apple Books 式大封面（右上角常驻进度圆环，下方常驻更多操作，悬停显示预览与收藏；添加格默认虚线加号，悬停展开提示）。支持拖放重排与跨书架移动，支持封面拖拽时的原位淡化与邻近让位；支持按住空格（iPad 长按）的封面摘要预览，优先展示本地完整译文与精读一句话概括，预览不触发翻译或精读。

## 3. 阅读器与双语重排

### 统一入口与导航
- **两种模式**：阅读器主入口统一为 **「原版」** 与 **「双语重排」**，由应用根据论文来源自动选择源码重排或本地 PDF 段落重排。
- **章节目录**：左侧目录只展示章、节两级，支持逐章或一键展开/收起及跳转文末总结；PDF 优先读取内嵌目录，缺失时从正文识别标题，否则回退页码导航。
- **准备页动画**：源码重排准备页在阶段标题上方展示居中翻页书本插画，播放/暂停共用主按钮；开启「减弱动态效果」时以静态开合书区分状态。

### 在线论文的源码重排
- 优先解析同版本 TeX 包，缺失或不完整时尝试同版本 HTML，均不可用时说明原因并提供原版 PDF。
- 源码仅作静态解析，不执行包内 TeX、脚本或代码；保留原文顺序、公式、图片、表格、图注与引用，不可靠时不发布残缺内容。
- 英文原段在前、简体中文译文在后；作者署名、机构、参考文献、代码与表格保留原文，行内公式保持原对象，图片内文字不翻译。
- 本地校验来源覆盖、去重、顺序与公式后按完整块追加发布为连续 HTML；已发布内容与锚点永不改写，重新生成保留旧版本与旧批注，原始 PDF 永不覆盖。

### 本地 PDF 的段落重排
- 默认按自然段连续上下展示英文与中文，宽屏支持切换为原页与译文并排；支持跨页连续滑动、页码跟随更新及目录/页码直跳。
- 进入重排即优先翻译当前页并在后台继续全文，翻页优先照顾当前可见页，复用本地译句缓存，支持暂停、继续与无译文时先读英文。
- 尽量保留完整可读正文并改善英文断字、字距、首页署名与参考文献识别；规则表格提取为可选字、可复制的结构化表格，复杂表格、图片与难配对公式在正文原位展示出版原貌，可随时核对原页。

## 4. 选区、高亮、页边笔记与图片预览

### 中英文独立选区与批注浮层
- 按手势起点语言锁定选区，中文与英文不互相夹杂，允许任意字符范围（不强制完整单词）；图片、表格与公式作为共享元素可选。
- 临时选区使用半透明深灰叠加，与已有各色高光可清晰区分；应用或取消标注后保持选区，点击正文空白处清除。
- 拖选后自动弹出统一批注浮层：首行选色立即生效、次行切换高亮/下划线、第三行添加书签、第四行添加阅读笔记；局部改色或取消仅影响选中范围，未选中的原标注保留。源码重排、本地 PDF 重排与原版 PDF 共用此浮层。

### 阅读笔记卡片与悬停交互
- 笔记独立于高亮存储：取消高亮不删除笔记，未高亮文字添加笔记不自动加高亮；支持实时在同一编辑区内渲染 Markdown 与 LaTeX，草稿自动保存，支持删除撤销与引用其他论文的本地笔记。
- 侧栏展开时使用选区附近浮卡；侧栏收起时优先右侧空白、次选左侧排布页边卡片，空间不足回退浮卡。页边卡片采用文档坐标跟随原生滚动，滚动期间不重新分配布局或晃动。
- 带非空笔记的原句下方以不规则手绘波浪线提示；正文与卡片支持双向 Hover 激活，标记整体轻浮（不留重影，单行约 2 pt、多行约 1 pt），平滑虚线直接连接页边卡片垂直中点并展开预览，跨越文字与卡片通道时不闪烁；点击卡片呈轻柔弹性展开（「减弱动态效果」下禁用弹性缩放）。

### 图片沉浸预览
- 点击 HTML 图片或图表裁片从原位等比放大居中，背景轻度模糊变暗；点击背景、图片、关闭按钮或按 `Esc` 回落原位。拖选经过图片不触发放大，不通过重渲染整篇正文实现预览。

## 5. 科研助理、AI 精读与长期记忆

- **共用模型配置与双档路由**：翻译、论文助读与书库助理共用当前选定服务与凭据；支持在「设置 → 模型服务」可选配置同一服务下的「轻量模型 ID」，用于本地 PDF 全文翻译、空闲记忆整理与静默笔记修订，主力/精读与复杂问答继续使用主模型。保存有效模型凭据后自动续接被中断的双语重排或翻译请求。书库助理多步检索从首轮即知晓工具轮数与调用预算，检索与思考过程可展开回查，最终结果以圆角卡片按序呈现，支持追问与澄清选择框。
- **证据优先与引用溯源**：论文问答以当前论文为主要证据，书库与授权 Obsidian 目录为补充；论文事实、外部资料与推断明确区分，引文编号与来源卡必须能定位到具体原文，禁止用其他论文替代缺失的当前论文证据。
- **AI 精读与文末总结**：在助读侧栏或由助理发起 AI 精读，用五色批注区分核心论点、概念、实证、让步与反驳、方法，并生成独立成页的中文文末总结（可原地编辑、自动保存、回查引文）。委托助理记笔记时一次保存原文标画与本地笔记，保留既有手工修改。
- **长期研究记忆**：记录研究兴趣、背景、偏好、进展与待查问题，保留来源并标注推测；用户可在「设置 → 研究记忆」查看来源、编辑或删除，自动提取与空闲整理绝不能覆盖用户修订或复活已删除记录。

## 6. Obsidian 导出与阅读日历

- **Obsidian 导出**：仅在用户点击「整理到 Obsidian」时写入用户授权目录；合并最新编辑版的文末笔记、逐条批注与出处，检测外部修改与重复追加并保留手写区；包含讨论内容时单独询问且只整理结论与待解问题。
- **阅读日历**：按本地日期归集前台阅读时长，当日每篇只列一行，跨午夜拆分、同篇及全日重叠时段去重；支持补记、展开单篇明细与删除误记，后台与长时间无操作保守计时。

## 7. 界面视觉与动效规范

- **设计语言**：参考 Claude 网站风格，采用暖纸色背景、深墨色文字、衬线标题与克制的陶土色强调；应用内菜单与列表使用纸色面板、陶土色勾选与逐行悬停反馈，支持键盘导航；文件授权与永久删除使用系统对话框。
- **原生材质与微交互**：macOS 26 / iPadOS 26 导航与悬浮控件组采用原生 Liquid Glass，低版本或开启「降低透明度」时回退纸色底。侧栏入口、书架切换、收藏五角星、日历翻页与各类操作图标具备克制的纸笔/版画风微交互。
- **减少动态效果**：启用系统「减弱动态效果」时，关闭页面位移、封面落定、弹性缩放与复杂图标动画，以静态状态清晰区分。

## 8. 范围外与后续目标

- **当前范围外**：iPhone 适配、多人实时协作、Windows / Android、全天候后台任务、扫描件 OCR、HTML 手写，以及不承诺任意复杂论文无损转换或不同兼容模型表现一致。
- **后续目标**：iCloud 自动同步、App Store 正式签名公证分发（待开发者账号与多设备真机验证就绪后推进）。
