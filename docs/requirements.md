# 需求基线

日期：2026-11-13。来源：本项目连续需求访谈。

本文记录产品承诺；实现建议和验证方法分别见技术选型与设计文档。

## 已确认

### R01 平台、用户与运行方式

Mac 是主要设备，iPad 支持 Apple Pencil 自由手写；两端都能独立检索、下载、解析、翻译、阅读和问答。第一版不包含 iPhone。面向作者及少量朋友，每人使用自己的资料与 API 配置，不提供团队共享论文库。

最低支持 macOS 15，优先 SwiftUI。无自建服务器；本地处理不代表大模型离线运行，翻译与问答调用用户配置的外部 API。

### R02 论文获取

输入完整或模糊标题。明确且唯一的匹配直接下载；模糊、多候选或版本身份不明确时，展示标题、作者、年份和来源，等待选择。无法获取全文时保留论文信息和来源链接，支持手动 PDF 导入。Mac 必须支持从 Finder 拖拽一个或多个 PDF，导入的本地 PDF 同样进入解析、重排及质量降级流程。

主要论文领域为计算机 / AI。论文检索和实际下载地址必须来自可验证的来源，不能使用模型凭空生成的链接。

### R03 双语重排与降级

英文原段在前，中文译文在后。公式、图表、图注、代码、引用和阅读顺序必须纳入质量检查。无法可靠重排时说明原因并使用普通 PDF 阅读和批注；不能只凭转换程序没有报错就宣称质量合格。

始终保留原始 PDF。重排阅读体验优先于宣称支持所有论文。

### R04 渐进翻译与页面冻结

先解析结构和准备排版，前几段翻译完成即可展示，其余内容在应用运行、用户阅读时继续处理。

用户已同意将最初的“整篇版式冻结”细化为“逐步追加固定页面”：已发布页面不再移动、插入内容或回填空白；完成的后续内容追加在其后。未完成部分可以预览原文，但不允许在尚未固定的重排内容上手写。

允许应用进入后台后暂停，恢复前台后继续；不要求锁屏或切出应用后无限持续翻译。

### R05 手写和文字批注

用户需要直接在重排文章上手写、画箭头、圈选和写公式，不接受仅文字高亮代替自由手写。两端展示同一份固定页面，通过缩放适配窗口；不能在另一设备重新计算版式导致笔迹错位。

划线选文后可询问 AI；普通 PDF 降级模式也能阅读和批注。

### R06 AI 与检索

翻译和问答共用用户在设置中自行配置的大模型 API，优先 GLM，并提供兼容接口；服务地址、模型与密钥都可修改。

划线问题优先结合当前论文全文语境解释选中的文字、公式或图表；整个论文库和用户指定的 Obsidian 目录是辅助资料。回答区分论文原意、其他来源的补充与模型推断，引用可定位。

### R07 Memory

自动整理并更新研究兴趣、知识背景、阅读进展和未解决问题。用户可以查看、修改、删除记忆。记忆保留来源，模型推测需标注。

聊天、原始批注、笔记和阅读事件作为独立记录保存；不是所有历史都必须转成长期记忆。

### R08 Obsidian

现有笔记库位于 iCloud Drive。应用读取用户指定范围用于辅助检索。

每篇论文对应一份 Markdown 笔记；只有点击“保存到 Obsidian”才写入阅读记录、批注和总结。后续保存更新该笔记且保留用户撰写的部分，避免重复追加。

每次保存询问“是否将本次讨论整理到笔记中？”。同意时根据上下文整理读者与 Agent 的问题、解释、讨论结论和未解决问题，而不是默认把聊天原文全部附上。

### R09 阅读日历

自动记录每天阅读的论文、估计阅读时长、批注和笔记活动；用户可补记或修正。跨设备记录合并，避免同一时间段重复计时。

### R10 同步与分发阶段

希望通过各自的 iCloud 账户同步应用资料。现在没有付费 Apple 开发者会员，用户接受软件成熟后再购买。

当前先开发可独立运行的本地功能。CloudKit 自动同步的签名、真机和多账户验证，以及面向朋友的便利分发，安排在会员可用后。同步能力仍属于完整第一版目标，不能把本地阶段宣称为多端同步已经完成。

## 设计默认值，不作为用户已经确认的事实

- iPadOS 18 暂定为最低版本；若用户设备更旧，需要重新确认。
- 当前以英文到简体中文为主；其他语言方向后续扩展。
- API Key 每台设备分别配置，不通过应用数据同步。
- 已下载的页面、原文、笔记和批注离线可读写；联网后才能继续在线翻译和问答。
- 第一阶段提供 GLM 和可配置的 OpenAI 兼容协议适配；不承诺每个同协议服务行为完全相同。
- 自动阅读计时只是估计，长时间无操作与后台时段需保守处理，并允许用户修正。
- 第一阶段不训练或打包本地大语言模型，不依赖另一个付费 embedding 服务。

## 第一版之外

iPhone、多人实时协作、公开 App Store 上架、任意论文无损转换、全自动识别所有手写内容、全天候后台任务、Windows / Android、在设备上执行下载论文附带的 TeX 或代码。

原始手写内容以图像和可编辑笔迹保留；识别或解释图表/手写是否可用取决于所配置模型的视觉能力，不默认认为文本模型能够看图。

## 2026-11-14 界面补充

用户要求整个 App 以视觉引导操作，突出主任务并弱化次要信息；减少解释性文字、重复口号与技术实现细节。通过 Computer Use 检查真实窗口的视觉与操作。

书库采用 Apple Books 式大封面，直接呈现论文标题，保留紧凑的继续阅读入口。封面悬停抬升，右上角常驻圆环显示阅读进度，收藏和更多操作仅悬停或聚焦时出现；触摸设备提供长按菜单。添加格默认只有虚线与加号，悬停后动画显示两行“拖拽 PDF 至此 / 或点击在线查找”。移除侧栏“正在阅读”入口，保留“继续阅读”；已读集合不显示添加格，左下保留 PDF 导入，所有集合支持拖放。

进度达到 100% 自动归入已读；全部论文始终把未读完的论文放在已读论文前面，每组内部保留所选排序，侧栏计数使用同一判断。末页已读状态保存后，回看前文不撤销，用户仍可主动标记未读。

右上入口改为书库 Agent。Agent 可查本地知识点和在线论文、准备导入、定位论文及具体页；真实工具结果用紧凑卡片呈现，点击完成导航或确认导入。当前论文划线问答继续以该论文为主要证据。不能把生成的链接或工具意图当作已执行结果。

## 主题书架与连续查找体验

用户确认每篇论文仅属于一个主题书架，拖拽表示移动归属。主题书架直接显示在全部论文页面，支持新建，不新增专用侧栏。移出书架回到未分类，删除书架不删除论文。在线查找在当前窗口内容区展开，通过布局过渡保留书架上下文，不再弹出二级界面。

主页书架栏进一步确定为可横向滑动的一行：首项固定“未分类论文”，随后为自建书架，末尾加号用于新建。界面减少重复标题、分区说明与叠放元素；选中状态用视觉表达。在书架内点击添加论文，导入到对应书架。

封面拖动参考 Apple Books：完整书封拿起并跟随鼠标，原位置淡化，邻近封面让位，松手落位、取消恢复。支持手动整理并保存自定义顺序，继续遵守全部论文未完成优先；跨书架的有效放置目标有清晰视觉反馈。

## 2026-11-14 重排与资料保留补充

用户确认接入 arXiv 同版本 HTML 优先重排，每篇只保留一份原始 PDF 和一套最终重排结果，可随时选择原版。HTML、下载副本和排版临时制品不长期保留；断点恢复、搜索、译文和批注定位所需记录继续保存。新导入不另外生成英文预览。已有带高亮、书签或笔迹的旧版式不能当缓存删除；无依赖的旧英文预览在双语结果完成后清理。

本轮实现范围：本地上传 PDF 在设备上提取文字和分栏；混合文档的复杂页完整保留原版几何，其余可靠文字重排。纯扫描件与全篇复杂文档仍回退原版；OCR、复杂页内部图表裁剪与 TeX 执行不属于本轮已实现能力。

## 2026-11-14 图片呈现补充

用户要求支持论文 SVG，不能因单图不支持让整篇回退。统一处理内嵌或引用图片、格式识别、比例、图注与多面板顺序；宽图和长图仍使用稳定、可缩放的固定页。转换失败说明具体位置，可靠匹配时保留对应原页；原始 PDF 始终可查看。

用户明确：SVG 内的文字不用翻译，保持原样；图注随正文翻译。图中文字或字形标记可在本地辅助完整性检查，不混入正文翻译输入或引用证据。

## 2026-11-14 原 PDF 裁剪补图

用户确认图片失败后可从原始 PDF 裁图替代，并要求使用简单算法、像素定位框定范围。SVG 与裁剪图内的文字保持原样，图注继续翻译。99% 为用户提出的裁剪成功率验收目标；成功必须覆盖图形、标签、图例与全部面板，不夹入相邻正文，不能把拒绝裁剪或保留整页算成功。当前没有代表性独立样本证实已达到该目标。


## 2026-11-14 HTML 连续阅读与性能确认

最终格式采用本地 HTML，供未来交互功能扩展。正文连续阅读，不采用纸张分页；已入库内容直接打开持久化结果，不重新转换或组合。每篇保留原始 PDF 与一套 HTML/必要资源，图片按内容去重，清除中间版本和下载缓存。这里的最终 HTML 是阅读制品，替代前述“HTML 全部作为中间文件删除”的约定。

手写内嵌另行设计；HTML 可以随窗口宽度重排，采用稳定内容块和文本范围定位，不把 PDF 几何批注强行迁入 HTML。此前 R04/R05 中固定页与 Pencil 的承诺继续适用于原始 PDF 和已发布旧 PDF 重排；新 HTML 的笔迹层暂不属于当前实现。

首次导入显示实际阶段与进度，并尽量减少重复解析；在线下载、模型翻译和本地处理分别计时。已入库首屏 100 ms、就绪阅读 16 ms 为性能目标，必须报告测量条件、冷启动及未达标边界，不能以文件读取时间代替用户看到首屏或实际滚动帧率。

## 2026-11-15 实际验收补充

用户要求真正流式翻译：仅发送文字段落，一条流式响应可包含多段，文字增量立即显示，完整段落逐段校验、保存，不能等整批完成才展示，也不能为每个段落新建连接。长文需要控制请求长度，网络会话复用。行内公式可以提供给模型作上下文但保持原样；独立公式不发送。论文助读与书库 Agent 的聊天同样即时显示模型文本增量。

HTML 应适配应用主题与阅读宽度，按语义组织标题、紧凑作者信息、英中段落、公式和图注，不复刻 PDF 纸张布局。SVG 图片与引用跳转必须在实际 Mac 构建中检查。无法可靠转换的局部仍明确保留原版，不能隐藏内容。

Mac 失去焦点不应中断正在翻译的连接；iPad 真正进入后台时允许暂停。中断或失败应说明原因，已完成段落保存，半段内容不作为完成结果发布。

用户进一步确认：全文原文在导入完成后即可连续阅读，未译段落显示加载占位，接收增量时仅动态扩展对应的待译区域；完成的段落不再替换原文节点或重新格式化。中文译文左侧细竖线，英中之间以 1px 分隔线区分；翻译忠实原意，以流畅的中文学术表达为主，不逐字硬译。表格整体保留原文（含表题和单元格），不进入模型翻译输入；图片各面板的图注仍各自紧随图片翻译。

## 2026-11-15 双语选文验收修正

英文是 HTML 选文、复制和聊天引用的唯一文本来源。跨段选择自动按阅读顺序收集英文并显示高亮/解释；选到中文时关联对应英文段落，不把英中重复送入对话。英文局部高亮同步标记该段整段译文，完成翻译或重开后保持关联。意译不具备可靠词语对齐，中文单独选择使用整段英文关联。原生选区背景改为按文字范围绘制，避免覆盖空白边距。旧 PDF 与旧 HTML 批注定位保留。


## 2026-11-15 中英文独立引用（取代上一节的新选文行为）

用户确认中英文分别选择、引用和高亮；按手势起点语言锁定跨段选文，中文不夹杂英文正文，英文不夹杂中文译文。图片、图表、公式是双方可选的共享元素；图注按语言区分，行内公式随所在语言句子选择，不重复收集另一语言的公式。新高亮不自动扩大到另一语言整段；中英文均按实际字符范围保存，允许选中部分单词（按后续验收修正）。拖动与引用保留所选文字，不自动补全。旧批注不静默改写。


## 2026-11-15 选文批注浮层

用户要求选文后自动弹出与应用风格一致的菜单：首行颜色，点击立即应用并以加深背景区分已选颜色；第二行切换高亮/下划线并立即生效；第三行添加书签；第四行添加笔记保留占位，暂不实现笔记行为。完整已标注选区显示取消高光（下划线显示取消下划线）。混合选区或局部改色/切换仅替换所选范围，未选中的原标注必须保留。当前实现面向 HTML 连续阅读，原 PDF 使用现有控件。


## 2026-11-15 选区反馈与部分单词验收修正

临时选区使用半透明深灰叠加在已有高光上，使选中和未选中的同色高光可区分，并避免与蓝色高光混淆。应用高光、下划线、换色或取消标注后仍显示选区，点击正文其他位置才清除。中英文独立标注均允许任意字符范围，取消英文完整单词限制；范围覆盖、语言过滤和共享对象规则不变。

## 2026-11-15 阅读笔记卡片（本地 HTML MVP 已实现）

点击已有高光/下划线或拖选后添加笔记，使用统一的 Markdown/LaTeX 笔记卡片，并保留标注颜色和模式编辑。侧栏展开时使用选区附近的浮卡，收起时优先在右侧空白分配页边卡片，右侧不足则左侧；空间不足允许回退浮卡。两种显示共用同一笔记和草稿。笔记独立于高光记录，取消高光不删除笔记，未标注文字添加笔记不自动增加高光。

每张卡片有显示空间上限：未激活可收起为摘要，Hover 时上浮、恢复清晰并展开；超出预算的正文内部滚动，不截断内容。正文与卡片可双向 Hover 激活，通过平滑虚线连接；编辑结束及未激活时隐藏连线。非空笔记的文字以区别于普通下划线的手绘感波浪线提示。默认预算、状态、动画、保存及验收边界见[阅读笔记设计](superpowers/specs/2026-11-15-inline-reading-notes.md)。

实现包含独立语言/对象锚点、Markdown/LaTeX 本地预览、草稿自动保存、删除撤销与显式 Obsidian 导出。Mac 构建后的实际窗口验收及未覆盖边界见 [MVP 状态](mvp-status.md)；iPad 构建不等同于触摸真机验收。原 PDF 笔记操作不在本轮范围。

用户追加：Markdown/LaTeX 必须在输入时实时编译显示；上下滚动不应让笔记卡片卡顿或反复晃动。编辑态同时呈现源码与实时预览，保留完整预览切换；页边卡片跟随原生文档滚动，编辑卡片保持位置，滚动期间不重新分配布局或重建动画节点。
