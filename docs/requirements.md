# 已确认需求

本文件归并截至 2026-11-23 的确认内容。实现与实测结果以 [MVP 状态](mvp-status.md) 为准。

## 平台与本地阶段

Mac 为主要设备，最低 macOS 15；iPad 可独立下载、解析、翻译、阅读和问答，不依赖常驻 Mac、Python 服务或自建服务器。第一版面向个人和少量朋友，各自管理资料与 API。先完成本地 MVP，不自行部署或上传资料。

iCloud 自动同步与分发是后续目标，待开发者会员、签名、真机与多账户验证可用后接入，不能把当前本地实现称为已支持同步。

## 论文获取与源码重排

线上按完整或模糊标题检索，来源和下载地址必须可验证；版本或候选不明确时展示作者、年份与来源供选择。主要领域为计算机 / AI。

阅读器主入口统一为「原版」和「双语重排」。应用根据导入来源选择重排方式，用户只需选一次阅读模式。

从在线查找或书库 Agent 下载的论文使用源码重排。导入时保存原始 PDF 并优先获取同版本 TeX 包。用户选择「双语重排」才开始解析与翻译。如果只下载到了 PDF，或 TeX 解析不完整，应用尝试同版本 HTML。两种源码都不可用时说明原因，提供原版 PDF 阅读。

通过 Finder 或系统文件选择器导入的本地 PDF 采用 PDF 文字层和原页图表重排。导入后可直接读原版、选择和批注，导入本身不调用模型。线上再次获取相同 PDF 时按哈希补齐来源，之后统一入口改走源码。已发布的历史版及用户记录继续可读，旧固定页转换任务停止续跑。

源码只作静态解析，不执行包中 TeX、脚本或代码。不凭字符数量、程序无报错或加载成功宣称完整转换。公式、图片、表格、图注、引用和原文顺序须保持；不可靠时不发布残缺内容。

## 本地导入 PDF 的逐句对照

用户确认英文 PDF 逐句对照的设计。带可靠文字层的 PDF 可由用户主动发起英译简中，宽屏对照原页和译文，窄屏逐句上下排列，两种布局都能双向核对原句。单页选区和本页翻译保留独立入口。无法可靠配对的内容标出范围和原因。完整交互、定位与验收条件见[逐句对照设计](superpowers/specs/2026-11-22-pdf-translation-reading.md)。

用户确认增加本地 PDF 的「段落重排」。按原文顺序展示英文自然段及其中文。上下滑动即可读过原页边界，原页码随阅读位置更新，目录和页码支持直接跳转。段内仍能按句核对、定位原页和复用已保存的译句；尚无译文时可以先读英文。进入段落重排即在后台翻译，当前页优先，随后自动处理完整篇论文。翻到新页时优先照顾正在阅读的页，已完成的译句可直接复用，读者可暂停和继续。图表、公式等内容保留原页定位，读者可以随时核查。

用户要求尽可能在连续阅读中读全原文，并能提取规则表格。表头、行列和数值有可靠依据时，直接展示可以选字、复制的表格，保留数值精度、上下标和有意义的强调。复杂表格与图片在相应正文位置展示出版原貌。难以配对的公式、文字或整页保留原版内容，优先在阅读位置就能看到。读者可自选返回原 PDF 核对。图表可在译文完成前阅读。题注和单元格识别须面向不同论文的版式，以原页文字、空间关系和绘制内容核查。跨论文检验同时检查错裁、错列和原有可读内容是否保留。

## 源码双语发布与稳定定位

英文原段在前，简体中文译文在后，按完整自然段处理。正文、标题、摘要、图注和实质性脚注翻译；作者、机构、通讯元信息不进入正文翻译，参考文献、代码和表格保留原文。行内公式保持原对象，图片中文字不翻译。

模型返回计划与流式译文，本地验证完整来源覆盖、去重、顺序和公式。先展示首批可读内容，其余继续生成；增量可预览，完整块才保存。暂停、取消、重启或更换模型不能覆盖已完成前缀，网络/鉴权错误明确提示，自动恢复有上限。

最终阅读格式为本地连续 HTML，不生成纸张分页。已发布内容与锚点不可改写；新内容追加。重新生成保留旧版本和用户记录，不迁移或重新解释旧批注。原始 PDF 永不覆盖。没有核验的 PDF 页码保持未知，源码块与版本可以独立定位。

Mac 失去焦点不取消任务；iPad 真正进入后台允许暂停。首屏 100 ms、阅读 16 ms 是性能目标，须报告设备、冷暖启动与测量边界，不当作已实现事实。重排请求优先降低思考等待，但请求参数不能证明服务实际零思考。

## 批注、问答与记忆

原版 PDF 与历史固定页继续支持高亮和 iPad Pencil 自由笔迹，笔迹绑定稳定页与版式；HTML 手写另行设计。HTML 按稳定内容块与文本范围定位，不强行迁移 PDF 几何批注。

翻译、论文助读和书库助理共用设置中当前选定的服务、模型和对应凭据。设置提供主流国内外服务预设和自定义兼容接口，带入官方地址与可编辑的建议模型。更换服务后，密钥只可用于对应的请求地址。当前论文是划线问答的主要证据，书库和授权 Obsidian 目录为补充；论文事实、外部资料与推断分开，引用可以定位。不能用其他论文替代缺失的当前论文证据。

长期记忆记录研究兴趣、知识背景、进展和待解决问题，保留来源并标注推测；用户可编辑或删除，自动提取不得覆盖修正或复活已删除记录。聊天、批注、笔记和阅读事件分别保存。

## Obsidian 与阅读日历

应用读取用户通过系统选择器授权的目录。每篇论文对应 Markdown 笔记，只在用户点击保存时写入，每次单独询问是否整理讨论；保留用户内容，检测外部修改和重复追加。讨论整理保留结论与未解决问题，不默认粘贴聊天原文。

日历记录前台阅读的论文、估计时长与活动，允许补记和修正；后台与长时间无操作保守计时。未来同步避免重叠会话重复计时。

## 设计默认值与范围外

iPadOS 18 暂定最低版本；当前主要支持英文到简体中文，密钥每台设备单独保存在 Keychain，不进入普通数据同步。已下载资料离线可读，翻译和问答需要联网。不承诺所有兼容接口一致、任意论文无损转换、全文离线模型、自动识别所有图像或手写。

iPhone、多人实时协作、公开 App Store 上架、Windows / Android、全天候后台任务不在当前范围。

## 2026-11-14 界面补充

用户要求整个 App 以视觉引导操作，突出主任务并弱化次要信息；减少解释性文字、重复口号与技术实现细节。通过 Computer Use 检查真实窗口的视觉与操作。

用户指定参考 Claude 网站的设计语言。书库、阅读工具和设置使用暖纸色背景、深墨色文字、衬线标题和克制的陶土色强调，保留 Apple 平台上的键盘、菜单和系统对话框交互。

书库采用 Apple Books 式大封面，直接呈现论文标题，保留紧凑的继续阅读入口。封面悬停抬升，右上角常驻圆环显示阅读进度，收藏和更多操作仅悬停或聚焦时出现；触摸设备提供长按菜单。添加格默认只有虚线与加号，悬停后动画显示两行“拖拽 PDF 至此 / 或点击在线查找”。移除侧栏“正在阅读”入口，保留“继续阅读”；已读集合不显示添加格，左下保留 PDF 导入，所有集合支持拖放。

进度达到 100% 自动归入已读；全部论文始终把未读完的论文放在已读论文前面，每组内部保留所选排序，侧栏计数使用同一判断。末页已读状态保存后，回看前文不撤销，用户仍可主动标记未读。

右上角使用一个开关控制当前窗口的右侧栏。在书库显示书库助理，阅读时可在论文助读、笔记和书库助理之间切换。窄窗口内仍以右侧栏呈现。Agent 可查本地知识点和在线论文、准备导入、定位论文及具体页；检索、阅读和筛选步骤按时间排列，答完后收起，可展开查看候选与数量。服务公开返回的思考文本或工作进展在本轮回答后仍可回看。最终推荐、引用和导航操作以独立圆角卡呈现，按助理选定的顺序显示，可点开来源或带着这项结果继续追问。遇到需要读者决定的范围，助理可以给出可点选的选项，也接受直接输入。书库与论文助读回答复用笔记的 Markdown 与公式渲染。在线论文来源与导入操作各有入口。回答中实际使用的引用可从编号或来源卡定位，其余检索资料默认收起。当前论文划线问答继续以该论文为主要证据。阅读目录只展示章、节两级，可以逐章或一次收起、展开。PDF 优先使用内嵌目录，再从正文识别章节标题；无法识别时使用页码导航。源码双语阅读按已发布的章节导航。不能把生成的链接或工具意图当作已执行结果。

## 主题书架与连续查找体验

用户确认每篇论文仅属于一个主题书架，拖拽表示移动归属。主题书架直接显示在全部论文页面，支持新建，不新增专用侧栏。移出书架回到未分类，删除书架不删除论文。在线查找在当前窗口内容区展开，通过布局过渡保留书架上下文，不再弹出二级界面。

主页书架栏进一步确定为可横向滑动的一行：首项固定“未分类论文”，随后为自建书架，末尾加号用于新建。界面减少重复标题、分区说明与叠放元素；选中状态用视觉表达。在书架内点击添加论文，导入到对应书架。

封面拖动参考 Apple Books：完整书封拿起并跟随鼠标，原位置淡化，邻近封面让位，松手落位、取消恢复。支持手动整理并保存自定义顺序，继续遵守全部论文未完成优先；跨书架的有效放置目标有清晰视觉反馈。


## 2026-11-15 中英文独立引用

用户确认中英文分别选择、引用和高亮；按手势起点语言锁定跨段选文，中文不夹杂英文正文，英文不夹杂中文译文。图片、图表、公式是双方可选的共享元素；图注按语言区分，行内公式随所在语言句子选择，不重复收集另一语言的公式。新高亮不自动扩大到另一语言整段；中英文均按实际字符范围保存，允许选中部分单词（按后续验收修正）。拖动与引用保留所选文字，不自动补全。旧批注不静默改写。


## 2026-11-15 选文批注浮层

用户要求选文后自动弹出与应用风格一致的菜单：首行颜色，点击立即应用并以加深背景区分已选颜色；第二行切换高亮/下划线并立即生效；第三行添加书签；第四行添加阅读笔记。完整已标注选区显示取消高光（下划线显示取消下划线）。混合选区或局部改色/切换仅替换所选范围，未选中的原标注必须保留。当前实现面向 HTML 连续阅读，原 PDF 使用现有控件。


## 2026-11-15 选区反馈与部分单词验收修正

临时选区使用半透明深灰叠加在已有高光上，使选中和未选中的同色高光可区分，并避免与蓝色高光混淆。应用高光、下划线、换色或取消标注后仍显示选区，点击正文其他位置才清除。中英文独立标注均允许任意字符范围，取消英文完整单词限制；范围覆盖、语言过滤和共享对象规则不变。

## 2026-11-15 阅读笔记卡片（本地 HTML MVP 已实现）

点击已有高光/下划线或拖选后添加笔记，使用统一的 Markdown/LaTeX 笔记卡片，并保留标注颜色和模式编辑。侧栏展开时使用选区附近的浮卡，收起时优先在右侧空白分配页边卡片，右侧不足则左侧；空间不足允许回退浮卡。两种显示共用同一笔记和草稿。笔记独立于高光记录，取消高光不删除笔记，未标注文字添加笔记不自动增加高光。

每张卡片有显示空间上限：未激活可收起为摘要，Hover 时上浮、恢复清晰并展开；超出预算的正文内部滚动，不截断内容。正文与卡片可双向 Hover 激活，通过平滑虚线连接；编辑结束及未激活时隐藏连线。非空笔记的文字以区别于普通下划线的手绘感波浪线提示。默认预算、状态、动画、保存及验收边界见[阅读笔记设计](superpowers/specs/2026-11-15-inline-reading-notes.md)。

实现包含独立语言/对象锚点、Markdown/LaTeX 本地预览、草稿自动保存、删除撤销与显式 Obsidian 导出。Mac 构建后的实际窗口验收及未覆盖边界见 [MVP 状态](mvp-status.md)；iPad 构建不等同于触摸真机验收。原 PDF 笔记操作不在本轮范围。

用户追加：Markdown/LaTeX 必须在输入时实时编译显示；上下滚动不应让笔记卡片卡顿或反复晃动。最新确认要求为在同一编辑区内实时呈现 Markdown/LaTeX，不另设预览窗格；页边卡片跟随原生文档滚动，编辑卡片保持位置，滚动期间不重新分配布局或重建动画节点。

用户追加：收起卡片保留五行中文摘要空间，展开和收起连续过渡；Hover 命中即响应，离开即回落，跨越文字与卡片间的有效通道时不闪烁。虚线增加方向和端点引导，波浪线采用平滑但不规则的手写形态。

中文标注点击修复：点击命中按实际文字边界，Hover 可适度扩展；旧双语联动高光按点击的语言进入笔记。上浮层必须保持跨行中文的实际字形位置，忽略 HTML 折叠空白，不产生重复字符。

点击笔记的弹出效果：虚线引导到卡片连接点，卡片从连接处扩展并轻微弹性回落，呈现果冻感；不移动正文、不反复晃动。快速切换或关闭需取消旧动效，减少动态效果模式禁用弹性缩放。

用户确认标记整体悬浮：文字、高光底色、下划线和笔记波浪线同步轻浮，原位置不留下色块或双影。单行约 2 pt、多行约 1 pt，不缩放文字；只转移选中范围，混合颜色和范围外原标记保留。图片、表格和独立公式保持原位反馈。

用户确认笔记虚线允许穿过论文文字，显示在文字和上浮标记上方，直接平滑连接页边卡片靠近正文一侧的垂直中点，让不同高度的两端自然弯曲，取消避让文字的绕行；不拦截正文交互，卡片内容仍位于连接线上方。


## 2026-11-15 图片沉浸预览

点击 HTML 图片从原位置等比放大居中，阅读区域背景高斯模糊并变暗，平滑过渡；点击背景、图片、关闭按钮或 Esc 回落原位置。保留引用图片入口，继续引用原始共享对象。SVG 与位图共用交互，不额外保存图片副本。拖选经过图片不触发放大，减少动态效果时不缩放。用户强调开关响应及时，不在点击后等待重新解码，不通过改变整篇正文状态实现预览。

## 英文换行、署名与参考文献

用户要求改善英文换行、作者信息和参考文献的阅读效果。保留原有复合词与引用编号，行末排印断字须能核回原句；难以辨认的字距保守处理。署名保留作者、机构和通讯信息的原有对应关系。参考文献按有依据的条目显示原文，文献区之前的正文和之后的附录仍可正常双语阅读。
