## 快速上手与论文获取

### 6 步快速上手
首次打开空书库时，应用会启动 6 步引导，依次带你认识导入与查找、模型服务设置、原版/双语切换、划线记笔记、笔记悬停预览以及 AI 精读与回顾，并可直接离线试读随包附带的两页示例论文 *When the Average Misleads*。之后随时可在 **「帮助 → 快速上手」** 或设置页重看。

### 添加论文的三种方式
- **本地导入 PDF**：从 Finder 直接拖入窗口，或点击左下角 **「导入 PDF」**。导入后立即可读原版、划线与记笔记，导入本身不调用任何模型。
- **书架在线查找**：点击书架首个加号格，默认并行检索 **arXiv、Crossref 与 DBLP**（可限定单一来源）。有开放全文直链或可核对的 DOI 开放 PDF 时，点击 **「下载并导入」** 自动入库；无法自动下载时可打开出版页，下载后在同一卡片点击 **「导入已下载的 PDF」**。
- **书库助理找论文**：直接让书库助理搜索新论文，或在阅读器右侧栏点击 **「相关论文」**（基于 Semantic Scholar 推荐）并一键导入。

> **去重与补齐**：导入完全相同的 PDF 会复用原记录，保留全部笔记与批注。若先本地导入、后在线找到同一篇论文，应用会按文件哈希补齐线上来源；之后「双语重排」将优先走源码路线，历史阅读版本仍可在版本菜单中查看。

### 整理与预览
- **主题书架**：每篇论文属于一个书架，支持拖放封面调整顺序或跨架移动；删除书架后论文回到「未分类论文」，不会被删除。也可直接让书库助理按主题建架并整理。
- **全库搜索**：在任意书架、收藏或已读页面输入关键词即可按标题搜索全库，点选候选自动跳转并高亮封面。
- **快速预览**：Mac 上指针停在封面上**按住空格**即可放大封面并预览摘要（有中文译文优先中文，已完成精读则置顶一句话概括），松开返回原位；也可从封面菜单打开。
- **常用快捷键（Mac）**：`⌘F` 文内查找、`⌘D` 当前页书签、`⇧⌘L` 返回书库、`⌃⌘S` 开关左侧栏、`⌥⌘I` 开关右侧栏、`⌘,` 打开设置。

## 原版与双语阅读

在阅读器顶栏可随时切换 **「原版」** 与 **「双语重排」**，点旁边的星标可收藏，省略号菜单切换未读 / 在读 / 已读或永久删除当前论文（需窗口确认）。宽屏下展开左侧目录栏时仍可同时显示页边笔记卡片，右侧助读侧栏支持拖拽左边缘调整宽度。

### 配置模型服务
翻译、论文助读和书库助理共用一套配置。打开 **「设置 → 模型服务」**，选择预设服务商（OpenAI、Claude、Gemini、DeepSeek、千问、Kimi、GLM、Mistral、Grok、豆包或自定义兼容接口），填入对应 API 密钥即可测试连接并保存。密钥按服务地址隔离保存在设备钥匙串中。

### 本地 PDF 的双语段落重排
- **连续阅读**：打开「双语重排」后，默认从当前原页开始按自然段上下排布英文与中文，可跨页连续滑动；顶部目录、底部页码输入与书签均可直接跳转。
- **当前页优先**：进入重排即优先翻译当前页并后台继续全文，翻到新页时会自动优先处理可见页；底部可随时查看进度、暂停、继续或针对缺译页重试，未配置密钥时也可先读英文重排段落。
- **版式与外观**：底部页码旁的 **「阅读外观」** 菜单可在「段落对照」与「原页与译文并排」间切换，并调整译文字号。
- **图表、公式与参考文献**：
  - 规则表格在能核对文字层时支持直接逐格选字和一键 **「复制表格」**；复杂表格、图片和独立公式在正文原位展示清晰裁片，点击可就地放大核对或查看原页。
  - 首页署名与参考文献保持原文并跳过翻译，正文附录自动恢复双语翻译。

### 在线论文的源码双语阅读
- 通过在线检索或助理下载的 arXiv 论文，优先静态解析同版本 **TeX** 源码，不完整时回退同版本 **HTML**，均不可用时说明原因并保留原版 PDF 阅读。
- 源码双语以连续 HTML 呈现，保留行内/独立公式、图片、表格与引用链接；首批段落通过本地校验后即可开读，其余在后台流式追加。重新生成会保留旧版本，原有批注不受影响。

## 划线与页边笔记

源码双语、本地 PDF 双语重排与原版 PDF 共用同一套选文批注体验：

- **按语言独立选文**：在双语视图中，按拖选起点锁定英文或中文，跨段不会互相夹杂；图片、表格和公式作为共享对象均可选择引用。
- **自动弹出批注浮层**：拖选任意文字后自动弹出浮层：
  1. 首行选择颜色立即应用标注；
  2. 第二行切换 **高亮 / 下划线**（已完整标注时可取消）；
  3. 第三行 **添加书签**；
  4. 第四行 **添加笔记**。
- **随时写笔记与实时预览**：单击已有高亮或下划线也能直接写笔记或重开旧笔记。编辑器在同一区域内实时渲染 **Markdown** 与 **LaTeX 公式**，草稿自动保存，删除支持撤销；点击链接按钮可按关键词引用其他论文中已保存的本地笔记。
- **手绘波浪线与双向 Hover 预览**：
  - 侧栏展开时，笔记以浮卡形式出现在选区附近；**侧栏收起时**，自动排布为页边卡片并跟随正文滚动。
  - 带有非空笔记的原句下方会显示手绘感波浪线。**将鼠标悬停在波浪线文字或页边卡片上**，原句整体轻浮、出现平滑虚线连接并展开完整预览；点击卡片即可原地编辑。
- **图片沉浸预览**：点击 HTML 中的图片或图表裁片可从原位平滑放大居中，点击空白处或按 `Esc` 回到原位。

## AI 精读与双入口助理

点击右上角侧栏按钮可打开助读侧栏：在书库中显示 **「书库助理」**，阅读时可在 **「论文助读」「笔记」「书库助理」** 之间切换。回答均支持 Markdown 表格、代码块、LaTeX 公式，并实时展示模型思考过程。

### 论文助读与 AI 精读
- **AI 精读**：点击 **「AI 精读」**，按核心论点、概念、实证、让步与反驳、方法五个维度在具体原句旁生成分色批注，并在文末生成独立的中文 **「文末总结」** 页（点击正文可原地编辑，引用编号可回查原文）。
- **划词提问与讨论记笔记**：选中原文可直接发问，回答以当前论文为主要证据，引文编号与来源卡均可定位回原文。讨论结束后，点击一键记笔记或告诉助理“把刚才的结论记在对应原文旁”，即可在核对引文后同步保存原文标画与笔记。

### 书库助理与研究记忆
- **跨库检索与整理**：可询问“我最近在哪几篇笔记里追查过样本构成？”，点击输入框左下角 **`@ 论文`** 可显式点选多篇本地论文做横向对比；也可让助理按主题整理未分类论文、建架移架、在线查找与导入论文。论文助读同样支持「新对话」开启新话题与展开回查工具调用步骤。
- **本地语义召回**：随包内置 4-bit 中英语义检索模型，离线即可跨语言查找笔记与长期记忆；每轮最多支持 16 轮工具、48 次调用，检索步骤答完自动收起并可展开回查。
- **回答习惯与记忆控制**：告诉助理你的回答偏好（如“以后看实验先讲对照条件”）后，两处助理共用该习惯；可在 **「设置 → 研究记忆」** 随时编辑、删除或溯源，并可按需开启空闲记忆整理与定期笔记整理。详见 [研究记忆设计](agent-memory.md)。

## 笔记汇总、Obsidian 与日历

- **阅读笔记库**：左侧栏 **「阅读笔记」** 按论文汇集文末总结与页边批注，支持展开历史精读、直接编辑正文或一键打开原文，返回后保留上次滚动位置与展开状态。
- **整理到 Obsidian**：在「阅读笔记」或阅读器「笔记」侧栏点击 **「整理到 Obsidian」**，授权你的本地库文件夹后，将文末总结、逐条批注与出处写入对应 Markdown 文件。重复导出不会覆盖手写区，包含讨论内容时会单独询问确认。
- **阅读日历**：左侧栏 **「阅读日历」** 按本地日期统计阅读时长，自动合并同篇重叠时段与跨午夜记录，支持展开单篇明细、删除误记与右上角手动补记。

## 数据存储与当前边界

### 数据存放在哪里
应用沙盒中的 `Application Support/PaperReader` 保存 SQLite 数据库、论文副本、源码包、HTML 与派生索引（快照显式迁移至 v14，保留历史批注与原文版本）。开发或隔离验收时可用 `PAPERREADER_DATA_DIR` 指定独立目录；切勿让两台设备同时写入同一份 SQLite 文件。

### 当前边界
- **在线全文**：取决于来源是否提供可验证的开放 PDF；arXiv 支持同版本源码重排，其他来源导入后支持本地 PDF 双语重排与原版阅读。
- **排版与扫描件**：扫描件 OCR 尚未接入；复杂跨栏图表、极少数不规则公式与动态 TeX 宏包会回退为原排裁片或原版 PDF 阅读。
- **平台与同步**：原版 PDF 支持 iPad Apple Pencil 手写，HTML 手写与 iCloud 自动同步尚未接入；Mac 与 iPad 各自独立运行。
