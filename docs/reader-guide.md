## 获取与阅读

首次打开空书库会自动进入 6 步快速上手引导（随时可从「帮助 → 快速上手」或设置重看），依次介绍导入与查找、模型配置、双语重排、划线记笔记、笔记悬停预览以及 AI 精读与回顾，并可直接离线试读内置两页示例论文。

在阅读器顶栏切换「原版」和「双语重排」，点旁边的星标即可收藏论文。省略号直接列出未读、在读和已读，当前状态带勾。点「双语重排」后，应用按书库中记录的来源处理论文。

- **在线下载的论文**通过书架的在线查找或书库 Agent 导入。应用优先使用同版本 TeX，源码包缺失或解析不完整时尝试同版本 HTML。两者都不可用时说明原因，可继续阅读原始 PDF。
- **本地导入的 PDF** 可从 Finder 拖入或通过「导入 PDF」添加，打开即可阅读原版。双语重排默认按英文段落配中文，图表随正文显示。应用先翻译当前页，再自动处理全文。
- 如果随后在线导入相同的 PDF，应用按文件哈希为同一篇论文补齐线上来源。此后「双语重排」使用源码，已有的历史阅读版本和批注仍可从阅读版本中查看。
- 在「设置 → 模型服务」选择服务，填写该服务的 API 密钥，即可测试连接或保存。内置 OpenAI、Anthropic Claude、Google Gemini、DeepSeek、阿里云百炼（千问）、月之暗面（Kimi）、智谱 GLM、Mistral AI、xAI Grok 和火山方舟（豆包）。选中预设会带入官方接口和建议的模型 ID，也可改填账户可用的模型。其他兼容服务选择「自定义兼容接口」。Mac 可按 `⌘,` 打开设置。
- 翻译、论文助读和书库助理共用一套模型配置。正常构建使用设备 Keychain，密钥按请求地址隔离。测试连接只发送固定的简短消息；保存后，翻译和问答使用新设置。

## 本地 PDF 的双语阅读

打开「双语重排」后，默认从正在读的原页开始，上下滑动就能连续读前后页。每个英文段落下面紧跟对应中文，原页交界处标出页码。拖选英文或中文即可在所选文字旁添加笔记。单击已有的高亮或下划线，可以写下或重开该处的笔记。整页尚无译文时，页码旁统一提示，可以先读英文。部分译文到达后，段内标记剩余空缺。已保存的译句直接从本机读取。滑到尚未处理的页，正在进行的页处理完后会优先补译新页。底部显示全文进度，可随时暂停或继续。返回书库后，已启动的翻译仍可继续。

底部页码旁的「阅读外观」菜单提供「段落对照」「原页与译文并排」及译文字号调整。应用记住选过的排法。在段落重排中，底部页码随滚动更新，也可以输入页码或点目录直接跳转。

图表随正文出现。表头、行列和数值能从 PDF 文字层核对时，表格可直接选字，跨格复制会按行和列分隔。可核对的两级表头保留出版版式，各列数值仍可选择，复制整组表头会保留跨列位置。含复杂公式或不规则合并格的表直接显示原版裁片。表上方的「复制表格」一次复制完整行列；需要查看右侧数据时，可在表内滑动或用列导航按钮。点原排图表或公式会就地放大，再点图中细节可以继续放大，关闭后接着读。表号和预览中的「查看原页」保留原 PDF 定位。识别和裁剪都在设备上完成。

首页署名按原文显示。可核对的多栏作者按人保留机构、邮箱和上标，版面交错时显示完整原排区域。参考文献可按条选择、复制，翻译队列会跳过已识别的书目，遇到附录恢复正文翻译。英文跨行时尽量还原词内断字并保留固有连字符。文字层漏空格时结合出版字距和词形核对。列表、章节名和公式前的说明可以选字；句子跨页、跨栏时，能核对的英文片段也可直接选字复制。独立公式与难以还原的区域随正文显示原貌，扫描页支持连续滑读。混合页上遇到能识别题注但无法确定边界的表，可以在同一阅读位置展开所在原页。也可在并排阅读时手动翻译本页，或只译一个单页选区。全文处理结束会标出缺译页和保留原版的页，缺译部分可单独重试。中文标注绑定到保存时的译文版本。扫描件 OCR 尚未接入。

## 源码双语内容

原段在前、中文译文在后，图表、公式和代码保留。标准 TeX 署名列在标题下，机构信息可展开。标准参考文献逐条列出，正文引用关联相应条目；遇到无法核对的作者年份命令会尝试同版本 HTML。源码按原文顺序组织；模型返回结构计划和译文，应用校验来源覆盖、顺序、对象和公式，完整块才发布。首批内容就绪后开始阅读，其余继续生成；可暂停、重启续接。输出截断和协议错误有界恢复，网络或鉴权失败明确暂停。

生成只追加新块，不改写已发布内容。重新生成创建新版本，旧阅读版本、批注、笔记与来源仍可访问。TeX 来源保留包哈希、主文件与块序号，没有核验的 PDF 页码保持未知。源码包不会执行，动态 TeX、复杂宏包、TikZ、特殊表格、缺失资源和扩展归档可能不受支持；不承诺任意论文无损转换。

HTML 与本地 PDF 段落重排均支持按语言跨段选文、复制、高亮、下划线、书签、问答与实时 Markdown/LaTeX 笔记。拖选任意中英文句子后会自动弹出批注浮层，可直接应用颜色、切换高亮/下划线或点击「添加笔记」；单击已有标注也能写下或重新打开该处笔记。收起侧栏阅读时，带笔记的句子下方会出现手绘波浪线并在页边排布摘要卡片；指针悬停在波浪线原句或页边卡片上时，原句轻浮、虚线相连并展开完整预览，点击卡片即可原地编辑。笔记草稿自动保存、删除可撤销。图片支持就地放大与引用，图片内文字不翻译。原版 PDF 与历史固定页支持原有高亮与 iPad 手写，HTML 手写尚未实现。

## 书库、助读与笔记

在任意书架、收藏或已读页面输入标题关键词，即可搜索整个书库。候选显示论文所在书架，点选后会跳到该书架并短暂标出封面。书库还支持排序、收藏、拖动整理与继续阅读。删除书架时，架内论文回到未分类。从封面菜单选择「删除论文…」，或点阅读器顶栏的纸篓图标，会打开系统确认窗口，显示论文名称。确认永久删除会清除应用里的文件副本、批注、笔记和阅读记录。最初选择的外部 PDF 和已经导出的笔记仍在原位置。Mac 快捷键为 `⌘F` 查找、`⌘D` 书签、`⇧⌘L` 返回书库。

在书架将指针移到封面上，按住空格即可预览，松开返回原处。也可以从封面菜单选择「预览论文」。本地导入时会定位并保存原文摘要，在线下载会复用同版本书目自带的摘要，缺失时从 PDF 提取。旧书库会在后台逐篇补齐。预览优先显示已保存的完整中文译文，有精读概括时会显示在摘要上方。

可以让书库助理按主题整理未分类论文、新建或改名书架、批量移动论文。导入本地 PDF 时，在助理卡片上选择文件。删除论文从助理结果卡进入，与手动删除共用同一个系统确认窗口。

书架和助理共用在线检索。默认并行查 arXiv、Crossref 和 DBLP，可以指定单一来源。书架先显示已经返回的论文，个别索引超时或限流时仍可使用其他来源。书架与助理的检索结果会在题名和作者中高亮实际命中的关键词。arXiv 先查 DataCite 登记的预印本，再按需查官方 Atom。相同 DOI 合并，索引明确关联的预印本和出版版本可以在卡片上切换。书库助理每个问题最多使用 16 轮工具、共 48 次调用。模型从第一轮就知道预算，每轮会收到剩余额度，留出时间筛选推荐并回答。

告诉助理“帮我下载这篇论文”，它会直接在线查找。在书架或助理的结果卡上点「下载并导入」，应用会使用已知的全文地址，或按 DOI 等书目编号查找公开 PDF，找到后直接加入书库。无法取得文件时，卡片保留出版页和「导入已下载的 PDF」入口。手动选入的新文件使用本地 PDF 双语重排。

在阅读侧栏找相关论文时，助理用 Semantic Scholar 根据当前文章给出推荐。它优先使用已登记的论文编号，本地 PDF 则用完整标题核对。也可以指定“找我写过的笔记”或“先查书库，缺了再下载”，让助理按所需范围检索。

阅读时，左侧目录展示章、节两级。点箭头展开或收起，点标题定位到正文。PDF 优先使用内嵌书签，缺少书签时从可选文字中识别标题；无法可靠识别时显示页码。源码双语阅读使用已发布的章节。

右上角侧栏按钮在阅读时打开论文助读、笔记和书库助理，在书库时打开书库助理。点回答中的引用编号或下方引用卡，可以跳到对应原页或已发布的源码段落。笔记摘录可在卡片里展开。书库助理会保留可展开的检索过程和服务提供的进展或思考文本。回答下方只列出最终选中的论文、引用和操作，每张卡都可以单独追问。需要缩小范围时，可点选助理给出的选项，也可直接输入。书库回答与论文回答支持 Markdown 表格、代码块和 LaTeX 公式。在线论文卡可以打开对应的来源页。没有全文索引的本地 PDF 可针对选区或当前页的可提取文字提问，回答引用对应原页。文本问答不识别图片或手写。

「阅读日历」把当天同一篇论文的阅读时间合在一行。展开单篇明细可删除有误的记录，右上角可补记。研究记忆可在「设置 → 研究记忆」中编辑、删除或查看来源论文。

和助理讨论后，可以说“把刚才的结论记在对应原文旁”。论文助读也提供一键记笔记。助理根据讨论整理 Markdown，在本地核对引文后一起保存标画和阅读笔记。点击回复中的笔记卡或侧栏「笔记」即可定位、编辑或删除。源码版沿用手工笔记的页边卡片。PDF 的手工选文与助理笔记共用原页标记和编辑器。无法区分重复引文时，可以选中目标原句再记。

在「论文助读」点「AI 精读」，段落旁会出现按维度标色的批注，说明具体引文怎样支持或限制作者的推断。打开「文末总结」，单击正文即可在原处修改，输入会自动保存。点击引用可以查阅出处。它用具体问题串起方法、关键实验和仍待验证的判断，每节可回查证据。从目录末尾打开，或在源码双语版中顺着正文向下阅读。使用「重新精读」可生成新分析。在书库侧栏打开「阅读笔记」，每篇论文默认展示最近一次精读，展开「历史精读」可重读之前的文末笔记，点「原文」可打开对应的 PDF。点笔记编辑器的链接按钮，可按关键词找到另一篇论文里写过的笔记。点击引用可预览最新笔记，并能打开继续编辑。书库 Agent 可按主题查笔记，助读问答与精读也会检索相关笔记。查询、更新索引都在设备上完成。[可直接复用的文末笔记提示词](../Sources/PaperReaderKit/Resources/Prompts/CloseReadingNotebook.md) · [AI 精读与笔记引用](requirements.md#批注问答与记忆)

完成 AI 精读后，点「整理到 Obsidian」即可把文末笔记、逐条批注和出处写入库中的 Markdown 文件。首次使用时选择 Obsidian 库或其中的笔记文件夹。在书库「阅读笔记」中可以打开文末笔记、展开批注并编辑，再次整理会更新同一个文件。Obsidian 中的手写区会保留，若手动改过自动生成区，应用会提示冲突。有对话需要一起整理时，可在助读侧栏「笔记」页的更多整理选项中单独确认。

## 回到上次的研究问题

在「书库助理」输入「我最近在哪几篇笔记里追查过样本构成？」。有可核查的记录时，点回答下的来源卡回到论文或手记。只问馆藏概况时，助理可以根据书架与代表论文回答。若希望留下新的研究问题，告诉它「这点我还想追查」，并写明问题。保存后的卡片和「设置 → 研究记忆」都可以更正或删除记录。

每篇馆藏只计一次。几篇题名相似能提示潜在方向；哪些判断来自你自己，还要看来源是手记、讨论原话，还是 AI 批注。应用已随包内置量化版中英语义检索模型，离线即可做跨语言笔记与记忆召回，并支持在「设置 → 研究记忆」中按需开启空闲记忆整理与定期笔记整理。要查看来源、双时态失效与撤回规则，见[研究记忆的工作方式](agent-memory.md)。

## 数据与兼容

应用沙盒的 Application Support/PaperReader 保存 SQLite、PDF、源码包、HTML、必要图片与用户记录。现有快照显式升级至 v14，保留笔记原文、创建时间和引用锚点。试用版中暂存的论文在升级时回到书库，可按新流程选择是否永久删除。未知版本拒绝打开。已发布旧 PDF/HTML 及其锚点保留读取能力。当前打开的 WebKit 文件受引用保护。

`PAPERREADER_DATA_DIR` 可指定隔离的开发/验收书库；沙盒构建仍要求目录可访问。不要让两台设备共同写入同一个 SQLite。真实论文、笔记、日志与构建产物不提交。

## 当前边界

线上获取全文取决于可验证的开放 PDF。arXiv 提供同版本源码的获取路线，其他在线来源导入后可以阅读原版。原文检索优先当前选区和结构。本地阅读笔记按中英文词项和标题检索，笔记修改后自动更新，下次打开书库时可从已保存的笔记重建。跨语言同义改写的召回有限。字体模板固定，没有重建旧版式 UI。复杂论文的图表、扫描页和数学排版取决于素材。iPad 模拟器构建与真机触控、Pencil 验收分别记录。
