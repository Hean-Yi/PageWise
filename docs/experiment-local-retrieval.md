# 本地轻量检索实验（A 方案）

分支：`experiment/local-semantic-lite`

## 目的

验证在不下载 E5（约 240 MB）的情况下，用本地词项 + 中英研究术语扩展 + 字符/词项回退，能保留多少检索质量与性能。

## 实现

- 普通阅读、笔记检索、记忆检索、笔记关系候选不再绑定 `DeviceSemanticEncoder`；
- 新增 `LocalSemanticLexicon`，只覆盖常见实验术语，不包含通用翻译；
- `Retriever.expandedTokens` 把原词和规范概念同时加入倒排索引；
- 设置页移除“下载语义模型”入口；
- `SemanticTextEncoder` 接口保留，方便未来替换成 <100 MB 的量化模型；
- 不打包任何模型文件，默认额外磁盘占用为 0。

## 同一基准结果

测试集为 16 个跨语言改写查询、3 个精确编号、3 个极性样本和 5 个无关查询；使用 `SemanticQualityProbe`。

| 指标 | 纯词项（E5 安装前基线） | 本地 A | E5-small |
| --- | ---: | ---: | ---: |
| 跨语言 Top-1 | 0/16 | 14/16 | 8/16 |
| 跨语言 Top-5 | 0/16 | 16/16 | 13/16 |
| 跨语言 MRR@5 | 0.000 | 0.938 | 0.630 |
| 精确编号 Top-5 | 3/3 | 3/3 | 3/3 |
| 极性 Top-5 | 3/3 | 3/3 | 3/3 |
| 极性 Top-1 | 2/3 | 2/3 | 3/3 |
| 无关查询误召回 | 0/5 | 0/5 | 0/5 |
| 检索 p50 / p95 | 0.75 / 4.7 ms | 0.48 / 3.2 ms | 22.3 / 27.1 ms |
| 进程峰值 RSS | 约 38 MiB | 约 38 MiB | 约 489 MiB |
| 冷启动首个查询 | 0 | 0 | 约 4.0 s |
| 模型磁盘 | 0 | 0 | 约 240 MB |

## 独立集与过拟合检查

原始 16 条包含大量已加入术语表的表达，上面的 14/16 有调参成分，不能代表泛化。

- 调参用留出集（16 条）：Top-1 16/16、Top-5 16/16；
- 未参与调参的第三组（12 条，教师/学生、梯度裁剪、束搜索、混合精度等）：本地 A Top-1 **5/12**、Top-5 **7/12**、MRR 0.486；
- 同一第三组 E5：Top-1 **11/12**、Top-5 **11/12**、MRR 0.917。

## 结论

- A 消除了 240 MB 模型、4 秒冷启动和约 489 MiB 常驻内存；
- 在已覆盖术语上提升明显，但静态术语表有明确泛化上限；
- 独立集上 E5 仍显著领先（Top-1 11/12 vs 5/12）；
- 精确编号、无关查询没有退化；极性 Top-1 仍少 1 条；
- 不能把 A 宣称为语义模型的等价替代；若跨语言泛化是核心指标，需要 <100 MB 的量化模型或持续扩充术语表。

## 验证

- 715 项串行测试通过；
- 严格格式检查、Mac App 构建、离线冒烟通过；
- E5 仅在对照实验中临时安装，已移除，不进入本分支默认路径。
