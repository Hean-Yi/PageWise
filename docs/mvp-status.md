## 实际技术与设计草案的区别

本地 MVP 使用 Core Text 处理普通 PDF 的可靠文字，使用 WKWebView 对净化 HTML 和受支持 MathML 显式分页。两条路径保留固定页契约；未接入 KaTeX。复杂本地页面保留原始几何，超出支持范围的 HTML 明确回退，不宣称任意论文无损重排。

已经保留段落 ID、固定页 ID、原始页码、缓存与恢复进度。尚未实现完整 LayoutRevision 分支管理、云同步 outbox、跨设备合并、资料导出/导入包。这些属于完整设计后续阶段。
